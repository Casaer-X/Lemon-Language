# v4.1.0 - IR 中间表示

## 新增

- **IRType.lm**: IR 类型系统
  - IRTypeKind: VOID/BOOL/I8/I16/I32/I64/F32/F64/PTR/FUNC/STRUCT/ARRAY
  - IRType: 类型定义（kind + bitWidth + elementType + fieldTypes）
  - 工厂方法: voidType/boolType/i8/i16/i32/i64/f32/f64/ptr/structType/arrayType
  - 类型查询: isInteger/isFloat/isPointer/isVoid/sizeInBytes

- **IR.lm**: SSA IR 指令定义
  - IROpCode: 40+ 操作码（算术/位运算/比较/内存/控制/转换/常量/其他）
  - IRValue: SSA 值引用
  - IRBasicBlock: 基本块（标签 + 指令列表 + 前驱/后继）
  - IRInstruction: 指令（操作码 + 操作数 + 结果类型 + 立即数）
  - IRPhiEntry: Phi 节点条目

- **IRFunction.lm**: IR 函数与模块结构
  - IRParam: 函数参数
  - IRFunction: IR 函数（参数 + 基本块 + 便捷指令构建方法）
  - IRModule: IR 模块（函数 + 字符串池 + 结构体定义）
  - IRStructDef: 结构体定义（字段名 + 字段类型）
  - 30+ 便捷指令构建方法: emitConstInt/emitBinOp/emitCmp/emitCall/emitBr/emitCondBr 等

- **IRGen.lm**: AST → IR 生成器
  - 函数/方法/构造函数生成
  - 语句生成: Expr/Return/VarDecl/If/While/For/Block
  - 表达式生成: 整数/浮点/字符串/布尔/变量/二元/一元/调用/字段/赋值/New/数组
  - 控制流: 条件跳转 + 基本块
  - 类型映射: TypeRef → IRType

- **LemonCompiler.lm**: 新增 `--target ir` 选项，输出 SSA IR 文本
