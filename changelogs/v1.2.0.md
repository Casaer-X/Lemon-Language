# Lemon Language v1.2.0 变更日志

**发布日期**: 2026-05-18

## 重大变更

### 枚举类型 (Enum Class)

Lemon 现在支持 Java 风格的枚举类型，包括带载荷的标签联合体（tagged union）：

```lemon
enum Color {
    Red,
    Green,
    Blue
}

enum TokenKind {
    Identifier(String),
    IntegerLiteral(long),
    StringLiteral(String),
    Eof
}
```

- 简单枚举变体：`Color.Red`
- 带载荷变体：`TokenKind.Identifier("foo")`
- 编译为 C 的 tagged union 结构体

### Match 表达式

新增模式匹配表达式，支持对枚举类型进行穷尽匹配：

```lemon
TokenKind kind = TokenKind.Identifier("x");
String result = match (kind) {
    TokenKind.Identifier(name) => "id: " + name,
    TokenKind.IntegerLiteral(v) => "int: " + v,
    TokenKind.StringLiteral(s) => "str: " + s,
    _ => "unknown"
};
```

- 支持变体模式（带绑定）、通配符模式、或模式
- 编译为 C 的 if-else 链

### Switch 语句

新增 switch-case 语句，用于基于值的分支选择：

```lemon
switch (x) {
    case 1:
        System.out.println("one");
        break;
    case 2:
        System.out.println("two");
        break;
    default:
        System.out.println("other");
}
```

### For-Each 循环

新增 for-each 循环语法，用于遍历数组：

```lemon
for (String item in items) {
    System.out.println(item);
}
```

### 字符串拼接运算符

`+` 运算符现在支持字符串拼接，并自动进行类型转换：

```lemon
String s = "Hello" + " " + "World";
String s2 = "Value: " + 42;
```

## 编译器变更

### 词法分析器
- 新增关键字：`enum`, `match`, `switch`, `case`, `default`, `in`
- 新增运算符：`=>` (fat arrow)

### 语法分析器
- 新增 `parse_enum_decl()` — 解析枚举声明
- 新增 `parse_match_expression()` — 解析 match 表达式
- 新增 `parse_switch_stmt()` — 解析 switch 语句
- 重构 `parse_for_stmt()` 为 `parse_for_or_foreach_stmt()` — 支持传统 for 和 for-each

### 语义分析器
- 新增 `EnumInfo` 结构体和 `enums` 存储
- 新增错误类型：`UndefinedEnum`, `UndefinedVariant`, `NonExhaustiveMatch`
- 新增 `check_match_pattern()` 方法

### C 代码生成器
- 新增 `generate_enum_struct_def()` — 生成 tagged union 结构体
- 新增 `gen_match_expr()` — 生成 match 表达式的 if-else 链
- 新增 `gen_string_concat()` — 生成字符串拼接代码
- 新增 `expr_is_string_type()` — 判断表达式是否为字符串类型
- 新增 `infer_enum_from_expr()` — 从表达式推断枚举类型
- 新增 `String_concat()` C 运行时函数
- 新增 StringBuilder/File/Character C 运行时实现

### 其他代码生成器
- `native_gen.rs` — 添加 Switch/ForEach/Match 占位实现
- `bc_gen.rs` — 添加 Switch/ForEach/Match 占位实现
- `nasm_gen.rs` — 添加 Switch/ForEach/Match 占位实现
- `jit/compiler.rs` — 添加 Switch/ForEach/Match 占位实现
- `ir/gen.rs` — 添加 Switch/ForEach/Match 占位实现
- `optimizer.rs` — 添加 Switch/ForEach/Match 优化遍历
