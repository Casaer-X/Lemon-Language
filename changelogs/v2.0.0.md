# v2.0.0 Changelog

## [2.0.0] - 2026-05-23

### JIT Compiler + Hot-Spot Optimization (A.5, A.4.14)

This is a major release that implements the full JIT compilation pipeline: bytecode→x86-64 machine code generation, hot-spot detection with automatic JIT triggering, and Windows x64 calling convention support.

#### JIT Compiler Rewrite (A.5)

Complete rewrite of `src/jit/jit_compiler.rs` with 50+ bytecode instructions now generating real x86-64 machine code:

| Category | Instructions |
|----------|-------------|
| **Stack** | PushConst, PushFloat, PushBool, PushString, PushNull, Pop, Dup, Swap |
| **Locals** | LoadLocal, StoreLocal, LoadGlobal, StoreGlobal |
| **Fields** | LoadField, StoreField (rbp-relative + rax-indexed addressing) |
| **Arithmetic** | Add, Sub, Mul, Div, Mod, Neg |
| **Float** | FAdd, FSub, FMul, FDiv, FCmp (SSE2 movq/addsd/subsd/mulsd/divsd/comisd) |
| **Bitwise** | BitAnd, BitOr, BitXor, BitNot, Shl, Shr |
| **Comparison** | Eq, Ne, Lt, Gt, Le, Ge (cmp+setcc+movzx pattern) |
| **Logical** | And, Or, Not |
| **Control Flow** | Jump, JumpIf (JNZ cc=5), JumpIfNot (JZ cc=4), Return |
| **Calls** | Call, CallMethod, CallNative, InvokeVirtual (placeholder) |
| **Objects** | New, NewArray, ArrayGet, ArraySet, ArrayLen, ArrayPush, Delete |
| **Types** | Cast (no-op), InstanceOf, TypeId, CheckNotNull (int3 on null) |
| **Optimized** | IncLocal(idx, delta) - single instruction increment |
| **Other** | Printf, Print, Println, Halt, Nop, Map/String ops |

#### x86-64 Code Generation Infrastructure (A.5.15-17)

- **Windows x64 calling convention**: rcx, rdx, r8, r9 for first 4 args, then stack
- **Stack frame layout**: push rbp; mov rbp, rsp; push rbx/rsi/rdi; sub rsp, locals_size
- **Local variable storage**: `[rbp - (idx+1)*8]` with 8-byte alignment
- **Register allocator**: `RegAlloc` struct maps local variables to r8-r15
- **Label/jump patching**: `PendingJump` system with 32-bit relative offset fixup
- **x86-64 encoding helpers**: 10 dedicated functions for push/pop/mov/mem operations
- **JitFunction metadata**: `frame_size`, `param_count` fields for runtime integration

#### Hot-Spot Detection & JIT Triggering (A.4.14)

- **Automatic hot-spot detection**: `call_function()` increments execution counts per function
- **JIT threshold**: Configurable via `set_jit_threshold()` (default: 100 calls)
- **Auto-compile**: When threshold reached, function is automatically JIT compiled
- **New LeVM APIs**:
  - `is_jit_compiled(func_idx)` — check if function has been JIT compiled
  - `get_jit_function(func_idx)` — get compiled function info
  - `get_execution_count(func_idx)` — get call count
  - `force_jit_compile(func_idx)` — force immediate compilation

#### JitState Enhancements

- `get_execution_count(func_idx)` — query per-function execution count
- `reset_counts()` — clear all execution counts
- Integrated into LeVM as internal state
