# v2.1.0 Changelog

## [2.1.0] - 2026-05-23

### NativeCodeGen Completion (B.1)

Major improvements to the native x86-64 code generator, completing critical missing features for standalone executable generation.

#### Control Flow (B.1.5-7)

- **Break statement**: Generates `jmp` to the nearest loop end label
- **Continue statement**: Generates `jmp` to the nearest loop continue label (for update)
- **Switch statement**: Generates comparison chain with `cmp + je` jump table, supports case patterns and default body
- **Loop label tracking**: Added `break_label` and `continue_label` fields to `NativeCodeGen`, properly saved/restored across nested loops

#### Expressions (B.1.10, B.1.16)

- **FloatLiteral**: Generates `mov rax, imm64` + `movq xmm0, rax` for SSE2 float loading
- **NullCoalesce** (`??`): Short-circuit evaluation with `test rax, rax; jnz not_null; eval_right; jmp end` pattern
- **ArrayAccess**: Generates `mov rax, [rcx + rax*8 + 16]` for LemonArray element access
- **Sizeof**: Type-aware size computation using `tsize()` instead of hardcoded 8
- **Unary operators**: Full implementation of:
  - `Plus` (no-op), `AddressOf` (no-op, already reference)
  - `PreInc`/`PreDec` with variable and field support (`inc rax`/`dec rax`)
  - `PostInc`/`PostDec` with push-old-value pattern

#### Infrastructure

- **`emit_jnz`**: New helper for conditional jump-if-not-zero (opcode `0F 85`)
- **Borrow checker fixes**: Pre-computed field offsets and variable offsets before mutable borrows
