# v3.6.0 - PE32+ 链接器

## 新增

- **PELinker.lm**: PE32+ 可执行文件链接器，将 NativeModule 链接为 Windows x64 .exe 文件
  - DOS 头 + PE 签名 + COFF 头 + PE32+ 可选头 + 段表 + 段数据
  - 段合并（.text 代码段, .data 数据段, .idata 导入表段）
  - 导入表生成（IDT + ILT + IAT + Hint/Name 表 + DLL 名称）
  - 导入 thunk 生成（jmp [rip + disp32] 间接调用）
  - 符号解析和重定位
  - LemonCompiler `--target native` 集成 PE 链接输出

## 修复

- 移除 Lemon 不支持的 `L` 后缀（`4194304L` → `4194304`）
