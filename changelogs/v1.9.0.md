# v1.9.0 Changelog

## [1.9.0] - 2026-05-23

### JIT Pathway Complete (A.2-A.4, A.6.1-4)

This release completes the JIT execution pathway, enabling the compiler to generate both native AOT code and bytecode for VM execution with an execution strategy decision system.

#### Bytecode Compiler Improvements (A.2)

All 14 TODO items in the bytecode compiler have been implemented:

| Task | Implementation |
|------|---------------|
| A.2.1 Enum support | Compile enums as classes with variant factory methods |
| A.2.2 ForEach loops | Compile as ArrayLen + ArrayGet iteration pattern |
| A.2.3 Switch statements | Compile as comparison chain with JumpIf |
| A.2.5 Match expressions | Compile with type checking (InstanceOf) + pattern matching |
| A.2.8 Unary operators | Plus, Deref, AddressOf, PreInc/PreDec, PostInc/PostDec |
| A.2.9 ArrayAccess assignment | Compile with correct stack ordering for ArraySet |
| A.2.10 Call target extension | Support indirect calls (placeholder for function pointers) |
| A.2.11 Cast actual conversion | Use Cast instruction with type index from string pool |
| A.2.12 InstanceOf actual check | Use InstanceOf instruction with type index |
| A.2.13 Sizeof actual calculation | Type-aware size computation (int=8, bool=1, ptr=8, array=16) |
| A.2.14 NullCoalesce fix | Proper Dup+JumpIf+Swap+Pop pattern instead of Shr mapping |

#### New Bytecode Instructions (A.3)

18 new instructions added with full serialization and VM execution support:

| Category | Instructions |
|----------|-------------|
| Array | `ArrayPush` (0x56) |
| Map | `MapNew` (0x57), `MapGet` (0x58), `MapPut` (0x59), `MapContains` (0x5A), `MapLen` (0x5B), `MapRemove` (0x5C), `MapKeys` (0x5D) |
| String | `StringConcat` (0x5E), `StringLen` (0x5F), `StringEquals` (0x63) |
| Type | `CheckNotNull` (0x64) |
| Float | `FAdd` (0x80), `FSub` (0x81), `FMul` (0x82), `FDiv` (0x83), `FCmp` (0x84) |
| Optimized | `IncLocal(idx, delta)` (0x90), `InvokeVirtual(vtable_idx, argc)` (0x91) |

#### VM Improvements (A.4)

- **`VMValue::Map`**: New variant for map values (Vec of key-value pairs)
- **All 18 new instructions**: Full execution logic in VM step()
- **`is_truthy`**: Map branch added (non-empty = truthy)

#### Execution Strategy Decision (A.6.1)

New module `src/ast/execution_strategy.rs`:

- **`ExecutionStrategy` enum**: `Aot`, `Jit`, `AotWithProfile`
- **`StrategyConfig`**: `aot_only`, `jit_only`, `enable_profiling` flags
- **`decide_strategy()`**: Per-member strategy with rules:
  1. `--aot-only` / `--jit-only` command-line overrides
  2. `reflect_` prefix methods → JIT
  3. Virtual methods → AOT (vtable needs deterministic addresses)
  4. Dynamic operations (InstanceOf, Match, Throw, Try) → JIT
  5. Default → AOT (with optional profiling)
- **`analyze_program()`**: Produces a complete strategy map for all functions/methods
- **Dynamic operation detection**: Recursive AST analysis for instanceof, match, throw, try/catch
