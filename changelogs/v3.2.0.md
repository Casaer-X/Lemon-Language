# v3.2.0 - x86-64 指令编码器

## 概述

Phase 3.1 完成：新增 x86-64 指令编码器，用于原生代码生成和 JIT 编译。

## 新功能

### X8664.lm

新建 `src_lem/codegen/X8664.lm`，实现 x86-64 机器码编码：

#### Reg 类 — 寄存器定义

- RAX-RCX-RDX-RBX-RSP-RBP-RSI-RDI (0-7)
- R8-R15 (8-15, 扩展寄存器)
- `isExtended(reg)` 判断是否为扩展寄存器
- `encode(reg)` 返回低 3 位编码

#### X8664 类 — 指令编码器

| 分类 | 指令 | 说明 |
|------|------|------|
| 数据移动 | MOV reg,imm32/imm64 | 立即数加载 |
| | MOV reg,reg | 寄存器间移动 |
| | MOV [mem],reg / MOV reg,[mem] | 内存读写 |
| | LEA reg,[rip+offset] | RIP 相对寻址 |
| 算术运算 | ADD/SUB reg,imm32 | 立即数加减 |
| | ADD/SUB reg,reg | 寄存器加减 |
| | IMUL reg,reg | 有符号乘法 |
| | IDIV reg | 有符号除法 |
| | CQO | RAX 符号扩展到 RDX:RAX |
| | NEG/NOT reg | 取负/取反 |
| 位运算 | AND/OR/XOR reg,reg | 逻辑运算 |
| | SHL/SAR reg,CL | 移位运算 |
| 比较测试 | CMP reg,reg/imm32 | 比较 |
| | TEST reg,reg | 测试 |
| 条件设置 | SETcc reg | 条件设置字节 |
| | MOVZX reg,reg8 | 字节零扩展 |
| 跳转 | JMP rel32 | 无条件跳转 |
| | Jcc rel32 | 条件跳转 |
| 函数调用 | CALL rel32 | 相对调用 |
| | CALL reg | 间接调用 |
| | RET | 返回 |
| 栈操作 | PUSH/POP reg | 入栈/出栈 |
| | SUB/ADD RSP,imm | 栈空间分配/释放 |
| 其他 | NOP | 空操作 |

#### 编码细节

- **REX 前缀**：自动生成 REX.W（64位操作）、REX.R（reg 扩展）、REX.B（rm 扩展）
- **ModR/M 编码**：支持寄存器-寄存器 (mod=3)、偏移寻址 (mod=1/2)、RIP 相对寻址
- **SIB 编码**：支持 SIB 字节（scale-index-base）
- **条件码**：E/NE/L/GE/LE/G/B/AE
- **调试输出**：`dump()` 方法输出十六进制字节序列
