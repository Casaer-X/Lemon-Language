# v3.5.0 - 虚拟机 (LeVM)

## 新增

- **LeVM.lm**: Lemon 嵌入式虚拟机，基于栈的解释执行引擎
  - VMValue 联合体模拟（tag + 字段方式: Null/Int/Float/Bool/String/Object/Array/Map/Ptr）
  - VMObject 对象模型（classIndex + fields 数组）
  - CallFrame 调用帧（funcIndex + pc + locals + stackBase）
  - VMMapEntry Map 条目
  - 完整指令解释执行：栈操作、局部变量、算术/位/比较运算、类型转换、控制流、对象/数组操作
  - 函数调用栈管理（支持顶层函数和类方法）
  - 步数上限保护（默认 10M 步）
  - 调试状态输出（dumpStack/dumpState）
- **LemonCompiler.lm**: bytecode target 集成 VM 信息输出
