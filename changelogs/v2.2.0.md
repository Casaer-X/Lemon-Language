# v2.2.0 Changelog

## [2.2.0] - 2026-05-23

### Hybrid AOT+JIT Compilation + Runtime Library (B.1.19-20, B.2, A.6.8)

This release implements the complete hybrid compilation pipeline: `--target hybrid` generates native x86-64 code with embedded bytecode, and provides a built-in runtime library for standalone execution.

#### `--target hybrid` Command Line (A.6.8)

- **`CompileTarget::Hybrid`**: New enum variant in `build_system::annotation.rs`
- **Hybrid compilation path** in `main.rs`:
  1. Compile AST to bytecode (`.lmb` format)
  2. Generate native x86-64 COFF object
  3. Link with embedded `.lmb` section via `link_hybrid_exe()`
- **`link_hybrid_exe()`**: New function that calls `pe_linker.add_embedded_lmb()` to embed bytecode data as a PE section, exporting `_lmb_data_start` and `_lmb_data_size` symbols
- **Usage**: `lemonc program.lm --target hybrid -o program.exe`

#### Built-in Runtime Library (B.2)

New `src/runtime/mod.rs` module with 17 C-compatible runtime functions:

| Category | Functions |
|----------|-----------|
| **Array** | `LemonArray_new`, `LemonArray_length`, `LemonArray_get`, `LemonArray_set`, `LemonArray_push` |
| **String** | `LemonString_length`, `LemonString_concat`, `LemonString_equals`, `LemonString_intToString`, `LemonString_floatToString`, `LemonString_join` |
| **I/O** | `LemonIO_print`, `LemonIO_println`, `LemonIO_readLine` |
| **VM Interop** | `LemonVM_init`, `LemonVM_callByName`, `LemonVM_destroy` |

Runtime data structures:
- `LemonObject`: Type ID + ref count + size header
- `LemonArray`: Length + capacity + data pointer (with auto-growth)
- `LemonMapEntry` / `LemonMap`: Key-value storage (structure defined)

#### VM Interop Functions (B.1.19-20)

- **`LemonVM_init(lmb_data, lmb_size)`**: Creates a LeVM instance from embedded bytecode
- **`LemonVM_callByName(vm, name)`**: Calls a VM function by name, returns i64
- **`LemonVM_destroy(vm)`**: Destroys the VM and frees memory

These functions enable native AOT code to:
1. Initialize the embedded VM at program startup
2. Call JIT-compiled functions from native code
3. Clean up VM resources at program exit
