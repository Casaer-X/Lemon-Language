# v3.1.0 - 字节码编译器

## 概述

Phase 4.2 完成：新增字节码编译器，将 AST 编译为 BytecodeModule。

## 新功能

### BytecodeCompiler.lm

新建 `src_lem/jit/BytecodeCompiler.lm`，实现 AST → BytecodeModule 编译：

- **两遍编译**：第一遍收集类/函数声明，第二遍编译方法/函数体
- **局部变量管理**：自动分配局部变量索引，支持 self/this 和方法参数
- **表达式编译**：
  - 整数字面量（自动选择 I8/I16/I32/I64）
  - 浮点/布尔/null/字符串/字符字面量
  - 变量访问和 this 引用
  - 二元运算（含短路逻辑运算 && / ||）
  - 一元运算（取负、逻辑非、位取反）
  - 赋值（变量赋值、字段赋值）
  - 函数调用和虚方法调用
  - 字段访问、new 表达式、数组访问
  - 三元条件表达式
- **语句编译**：
  - 变量声明、return、表达式语句
  - if/else 条件语句（含标签跳转）
  - while 循环
  - 块语句
- **标签管理**：freshLabel/patchLabel 实现跳转目标

### LemonCompiler 集成

- `--target bytecode` 现在调用 BytecodeCompiler 生成字节码
- 输出字节码的可读文本表示（.lmb 文本格式）
- `dumpBytecodeModule` 方法：将 BytecodeModule 转储为可读文本
