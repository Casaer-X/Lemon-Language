# v3.0.0 - 字节码指令定义

## 概述

Phase 4.1 完成：定义 Lemon 虚拟机的字节码指令集和核心数据结构。

## 新功能

### Bytecode.lm

新建 `src_lem/jit/Bytecode.lm`，包含完整的字节码指令集定义：

#### OpCode 类 — 60+ 条字节码操作码

| 分类 | 操作码 | 数量 |
|------|--------|------|
| 栈操作 | NOP, PUSH_NULL/TRUE/FALSE, PUSH_I8/I16/I32/I64, PUSH_F32/F64, PUSH_STR, POP, DUP | 13 |
| 局部变量 | LOAD_LOCAL, STORE_LOCAL, LOAD_FIELD, STORE_FIELD, LOAD_STATIC, STORE_STATIC, LOAD_THIS | 7 |
| 算术运算 | IADD/ISUB/IMUL/IDIV/IMOD/INEG, LADD/LSUB/LMUL/LDIV/LMOD/LNEG, FADD/FSUB/FMUL/FDIV/FNEG, DADD/DSUB/DMUL/DDIV/DNEG | 22 |
| 位运算 | IAND/IOR/IXOR/ISHL/ISHR/INOT, LAND/LOR | 8 |
| 比较运算 | ICMP_EQ/NE/LT/GT/LE/GE, LCMP_EQ/NE, FCMP_EQ/LT, DCMP_EQ/LT, ACMP_EQ/NE | 14 |
| 类型转换 | I2L/I2F/I2D, L2I/L2F/L2D, F2I/F2L/F2D, D2I/D2L/D2F | 12 |
| 控制流 | JMP, JMP_TRUE/FALSE, CALL, CALL_VIRT/IFACE/NATIVE, RET/RET_VOID | 9 |
| 对象操作 | NEW_OBJ, NEW_ARR, ARR_LEN/GET/SET, INSTANCEOF, CHECKCAST | 7 |
| 异常处理 | THROW, TRY_ENTER/EXIT, CATCH | 4 |
| Match | MATCH_ENUM, MATCH_TAG | 2 |
| 调试 | LINE_NUM, FILE_MARK | 2 |

#### BytecodeInstruction 类

- 操作码 + 操作数（int/long/double）+ 行号
- 工厂方法：withOperand, withLong, withDouble
- toString() 反汇编输出

#### BytecodeFunction 类

- 函数名、所属类名、局部变量数、参数数
- 指令数组 + 局部变量名数组
- emit/emitWithOperand/emitWithLong/emitWithDouble 便捷方法
- addLocal/findLocal 局部变量管理

#### BytecodeClass 类

- 类名、父类、接口列表
- 方法数组、字段名/类型数组、实例大小
- addField/findField 字段管理

#### BytecodeModule 类

- 字符串常量池、顶层函数数组、类数组、main 入口类名
- addString（去重）字符串池管理
- findClass/findFunction 查找方法
