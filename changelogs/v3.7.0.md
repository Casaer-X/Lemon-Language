# v3.7.0 - JIT 编译器

## 新增

- **JitCompiler.lm**: JIT 编译器，将 BytecodeModule 中的热点函数编译为 x86-64 机器码
  - JitState: JIT 状态管理（执行计数、热点检测、编译阈值）
  - JitCompiledFunction: 编译后的函数信息（代码、帧大小、参数数量）
  - PendingJump: 待修复跳转（标签位置、补丁偏移）
  - 基于栈的 JIT：使用 x86 栈作为值栈，rbp 相对寻址访问局部变量
  - Windows x64 调用约定（RCX/RDX/R8/R9 传参）
  - 完整指令编译：栈操作、局部变量、算术/位/比较运算、控制流、对象/数组操作
  - 跳转目标补丁机制（标签 + 待修复跳转列表）
  - LemonCompiler `--target bytecode` 集成 JIT 编译输出

## 修复

- `int[]` 数组声明替换为 `Array<int>`（Lemon 不支持 C 风格数组）
- 十六进制字面量 `0x94` 等替换为十进制（Lemon 不支持 0x 前缀）
- `X8664.Reg` 替换为直接导入 `Reg` 类
- `Double.doubleToLongBits` 替换为占位符（Lemon 无此方法）
