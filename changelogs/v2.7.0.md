# v2.7.0 - AST 优化器

## 概述

Phase 6.1 完成：新增 AST 优化器，支持常量折叠、常量传播、死代码消除和代数化简。

## 新功能

### AST 优化器 (Optimizer.lm)

新建 `src_lem/ast/Optimizer.lm`，基于 Rust 版 `src/ast/optimizer.rs` 实现：

- **常量折叠**：编译期计算常量表达式
  - 整数运算：`3 + 4` → `7`，`2 * 5` → `10`
  - 浮点运算：`1.5 + 2.5` → `4.0`
  - 布尔运算：`true && false` → `false`，`true || false` → `true`
  - 字符串拼接：`"hello" + " world"` → `"hello world"`
  - 字符串比较：`"a" == "b"` → `false`
  - null 比较：`null == null` → `true`
  - 一元运算：`-5` → `-5`，`!true` → `false`，`~0` → `-1`

- **代数化简**：
  - `x + 0` → `x`，`0 + x` → `x`
  - `x * 1` → `x`，`1 * x` → `x`
  - `false && x` → `false`，`true || x` → `true`

- **常量传播**：
  - `var x = 5; var y = x + 1` → `var y = 6`
  - 赋值时自动清除常量环境
  - 循环体内赋值的变量自动失效

- **死代码消除**：
  - `if (true) { ... }` → `{ ... }`
  - `if (false) { ... }` → 删除
  - `while (false) { ... }` → 删除
  - 纯表达式语句（无副作用的表达式）→ 删除
  - 空块 → 删除

- **自增/自减保护**：`i++`、`i--` 等有副作用的运算符不进行常量传播

### 编译流程集成

在 `LemonCompiler.lm` 中集成优化步骤：
- 语义分析 → **优化** → C 代码生成
- 输出优化统计信息（常量折叠数、常量传播数、死代码消除数）

## 辅助类

- `ConstValue`：常量值类型（Int/Float/Bool/Null）
- `OptimizerStats`：优化统计信息
