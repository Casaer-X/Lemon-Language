# v2.9.0 - NASM x86-64 汇编生成器

## 概述

Phase 3.5 完成：新增 NASM x86-64 汇编代码生成器基础框架。

## 新功能

### NasmCodeGen.lm

新建 `src_lem/codegen/NasmCodeGen.lm`，生成 Windows x64 调用约定的 NASM 语法汇编代码：

- **段结构**：生成标准 NASM 三段（.data / .bss / .text）
- **外部函数声明**：声明所有 C 运行时函数（printf, malloc, String_*, LemonArray_*, LemonMap_*, File_*, StringBuilder_*）
- **函数序言/尾声**：标准 push rbp / mov rbp,rsp / sub rsp,256 序言，被调用者保存寄存器保护
- **Windows x64 调用约定**：RCX/RDX/R8/R9 传参，32 字节影子空间，16 字节栈对齐
- **类生成**：构造函数（分配实例 + memset 初始化 + 执行构造体）、方法、析构函数
- **表达式生成**：
  - 整数/浮点/布尔/null/字符串/字符字面量
  - 变量访问和 this 引用
  - 二元运算（加减乘除取模、比较、位运算、逻辑运算）
  - 一元运算（取负、逻辑非、位取反）
  - 赋值（变量赋值、字段赋值）
  - 函数调用和方法调用
  - 字段访问、new 表达式、数组访问、三元表达式
  - 类型转换（cast）
- **语句生成**：
  - 变量声明、return、表达式语句
  - if/else 条件语句
  - while 循环（含 break/continue）
  - 块语句
- **字符串常量管理**：freshStringLiteral 生成唯一名称，.data 段定义
- **Main 入口**：自动查找含 main 方法的类，构建 args 数组并调用

### LemonCompiler 集成

- `--target nasm` 现在调用 NasmCodeGen 生成汇编代码
- 输出文件扩展名自动从 `.c` 调整为 `.asm`

## 使用方式

```bash
# 生成 NASM 汇编
lemonc src.lm --target nasm -o output.asm

# 用 NASM 编译 + GCC 链接
nasm -f win64 output.asm -o output.obj
gcc output.obj -o output.exe
```
