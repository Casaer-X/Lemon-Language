# v2.8.0 - 多目标编译框架与源码注解

## 概述

Phase 2.2 + 2.3 完成：多目标编译支持框架和源码注解解析。

## 新功能

### 2.2 多目标编译支持

- `compileFiles` 方法新增 `target` 参数，根据目标选择代码生成后端
- 支持的目标：`c`（默认）、`nasm`、`native`、`bytecode`、`hybrid`
- 根据目标自动调整输出文件扩展名（`.c` → `.asm` / `.lmb`）
- 代码生成器分发框架：后续添加新后端只需在 `compileFiles` 中添加分支
- 命令行参数验证：未知目标给出警告并回退到 `c`

### 2.3 源码注解解析

- Lexer 新增 `compileAnnotations` 字段和 `getCompileAnnotations()` 方法
- `skipLineComment` 方法增强：检测 `// @compile key=value` 格式的注解
- 注解值提取：读取 `@compile` 后面的内容作为注解值
- LemonCompiler 集成：从每个文件的 Lexer 中收集注解，解析 key=value 对
- 注解应用：`target` 注解可覆盖命令行 `--target` 参数

#### 支持的注解

```
// @compile target=native
// @compile optimize=2
// @compile output=myapp.exe
// @compile dep=math,io
// @compile entry=true
```

## 修复

- 修复链式方法调用代码生成问题：避免 `.` 语法导致的错误 C 代码生成
  - 将链式调用拆分为中间变量（如 `content.substring(0).trim()` → `sub = content.substring(0); value = sub.trim()`）
