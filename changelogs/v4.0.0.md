# v4.0.0 - 运行时库与混合执行

## 新增

- **Runtime.lm**: Lemon 原生运行时库
  - 40+ 运行时函数注册（内存管理、数组操作、字符串操作、I/O、类型操作、对象操作、Map 操作）
  - 函数签名管理（名称、参数数量、返回类型）
  - C 运行时头文件生成 (`generateCHeader`)
  - C 运行时实现生成 (`generateCImplementation`)
  - 运行时函数查询和检查

- **ExecutionStrategy.lm**: 执行策略决策分析器
  - ExecutionStrategyKind: AOT/JIT/INTERPRET/HYBRID 四种策略
  - FunctionStrategy: 函数级策略（复杂度估算、调用频率、动态分派检测）
  - ExecutionStrategyAnalyzer: 基于 AST 分析的策略决策
  - 使用 StmtKind/ExprKind 类型标签替代 `is` 操作符
  - 入口点自动标记、策略自动决策

- **LemonCompiler.lm**: `--target hybrid` 混合执行集成
  - AOT 方法 → NativeCodeGen → COFF
  - JIT 方法 → BytecodeCompiler → .lmb
  - 策略分析 + 运行时库信息 + PE 链接器

## 修复

- `Object` 类型替换为 `Declaration` + `DeclKind` 类型标签
- `is` 操作符替换为 `kind == StmtKind.XXX` / `kind == ExprKind.XXX`
- `ClassDecl.methods` 替换为 `ClassDecl.members` + `ClassMemberKind` 过滤
- `MethodDecl.isStatic` 替换为 `modifiers` 数组检查
- `FunctionDecl.body` 类型从 `BlockStmt` 修正为 `Block`
