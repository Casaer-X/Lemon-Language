# v3.3.0 - 原生代码生成器 (NativeCodeGen)

## 新增

- **NativeCodeGen.lm**: 原生代码生成器，将 AST 直接编译为 x86-64 机器码
  - 使用 X8664 指令编码器生成机器码字节
  - Windows x64 调用约定（RCX/RDX/R8/R9 传参，32 字节 shadow space）
  - 支持函数、方法、构造函数编译
  - 支持二元/一元运算、条件跳转、循环、赋值、字段访问
  - 字符串字面量通过数据段引用
  - 生成 NativeModule 结构（函数列表 + 数据段 + 外部符号表）
  - LemonCompiler 中集成 `--target native` 输出可读的机器码转储

## 修复

- 修复 lemonvm.rs 中 `jit_compiler` 缺少 `mut` 声明的编译错误
