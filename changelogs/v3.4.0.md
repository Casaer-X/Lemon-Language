# v3.4.0 - COFF64 目标文件生成器

## 新增

- **COFF64.lm**: COFF64 目标文件生成器，将 NativeModule 包装为 Windows x64 .obj 文件
  - COFF 文件头生成（Machine=AMD64, 段数, 符号数）
  - 段表生成（.text 代码段, .data 数据段，含属性标志）
  - 符号表生成（函数符号、数据符号、外部符号、段符号）
  - 重定位表支持（IMAGE_REL_AMD64_ADDR32NB, IMAGE_REL_AMD64_REL32）
  - 字符串表管理（长符号名存储）
  - `buildFromNativeModule()` 从 NativeModule 自动构建完整 COFF 结构
  - `serialize()` 序列化为字节数组
  - `dump()` 可读文本转储
- **LemonCompiler.lm**: `--target native` 集成 COFF64 生成，同时输出可读文本和 .obj 文件
