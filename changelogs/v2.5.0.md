# v2.5.0 Changelog

## [2.5.0] - 2026-05-24

### Phase 2.1: --build Project Build Mode

Added `--build` mode to the Lemon compiler for automatic project compilation.

#### --build Mode

- **Directory scanning**: `scanDir()` recursively finds all `.lm` files in a directory
- **Test file filtering**: Automatically skips files matching `test_*.lm` or `*Test.lm` patterns
- **Directory filtering**: Skips hidden dirs, `target`, `build`, `build_t1/t2/t3`, `output`
- **Sorted compilation**: Files are sorted alphabetically for deterministic build order
- **Default output**: Uses directory name as output filename (e.g., `src_lem/` → `src_lem.c`)
- **Usage**: `lemonc --build [dir] [-o output.c]`

#### File Runtime Extensions

- **`File_listDir(const char* dirPath)`**: Returns a `LemonArray*` of directory entry names
  - Cross-platform: uses `FindFirstFileA`/`FindNextFileA` on Windows, `opendir`/`readdir` on POSIX
  - Automatically skips `.` and `..` entries
- **`File_isDir(const char* path)`**: Returns 1 if path is a directory, 0 otherwise
  - Cross-platform: uses `GetFileAttributesA` on Windows, `stat`/`S_ISDIR` on POSIX

#### String Runtime Extensions

- **`String_compareTo(const char* a, const char* b)`**: Returns strcmp result, handles NULL inputs
- **`String_lastIndexOf(const char* s, int32_t ch)`**: Returns last index of character, or -1

#### Rust Compiler Sync

- Updated `src/codegen/c_gen.rs` with matching `File_listDir`, `File_isDir`, `String_compareTo`, `String_lastIndexOf` runtime functions
- Updated `src/ast/semantic.rs` to recognize `listDir` and `isDir` as File builtin methods
- Added `#include <windows.h>` / `#include <dirent.h>` / `#include <sys/stat.h>` headers

#### SemanticAnalyzer Updates

- Added `listDir` and `isDir` to File builtin type method list
