# Lemon Language v1.1.0 变更日志

**发布日期**: 2026-05-18

---

## 重大变更

### 方法访问规范 (Java-style Method Access)

Lemon 现在强制执行 Java 风格的方法访问规范：

- **外部调用静态方法**: `类名.方法名(参数)` — 如 `Math.abs(-42)`
- **调用实例方法**: `对象.方法名(参数)` — 如 `obj.greet()`
- **类内部调用实例方法**: `this.方法名(参数)` — 如 `this.getValue()`
- **类内部调用静态方法**: `类名.方法名(参数)` — 如 `Calculator.add(1, 2)`
- **禁止裸方法调用**: 不再允许省略 `this.` 或 `类名.` 前缀

编译器会在语义分析阶段检测裸方法调用并报错 (S016)。

### 主类名不再硬编码为 App

程序入口类不再要求必须命名为 `App`，任何含有 `public static void main(String[] args)` 方法的类均可作为入口点。编译器会自动搜索所有类中的 `main` 方法。

## 已知限制

- 字节码生成器尚未支持 `Delete`, `InstanceOf`, `Sizeof`, `TypeId`, `Lambda`, `Throw` 表达式
- JIT 编译器的 Lambda 和 Throw 为桩实现
- `this.method()` 和 `obj->method()` 在 AST 中产生不同的节点类型 (`Call(FieldAccess(...))` vs `MethodCall(...)`)
- 自举所需的关键特性尚未实现：enum/代数数据类型、模式匹配、StringBuilder、文件 I/O
