# Lemon Language v1.3.0 变更日志

**发布日期**: 2026-05-19

---

## 重大变更

### 自举计划 Phase 2 & 3 完成 — Lemon 版词法分析器和语法分析器

Lemon 语言现在可以用自身重写编译器前端。这是自举计划的关键里程碑：

- **Phase 2**: 用 Lemon 重写词法分析器 — ✅ 完成
- **Phase 3**: 用 Lemon 重写语法分析器 — ✅ 完成

Lemon 版编译器前端（Lexer + Parser）已通过验证，与 Rust 版输出完全一致。

### Lemon 版词法分析器 (src_lem/lexer/)

| 文件 | 说明 |
|------|------|
| `Span.lm` | 位置信息类 |
| `TokenKind.lm` | Token 类型常量（60+ 种） |
| `Token.lm` | Token 类 |
| `Lexer.lm` | 词法分析器实现 |
| `LexerTest.lm` | 测试用例（10 个 + Self-lex） |

验证结果：对 5 个 .lm 文件的 token 输出与 Rust 版完全一致（仅差 EOF token）。

### Lemon 版语法分析器 (src_lem/parser/)

| 文件 | 行数 | 说明 |
|------|------|------|
| `AST.lm` | ~800 | 完整 AST 节点定义（46 个声明） |
| `Parser.lm` | 1773 | 递归下降解析器 + Pratt 表达式解析 |
| `ParserTest.lm` | ~300 | 测试用例（5 个 + 自解析 8 个 .lm 文件） |

验证结果：对 8 个 .lm 文件解析出 61 个声明，与 Rust 版完全一致。

## 编译器 (lemonc) 修复与增强

### 代码生成器 (c_gen.rs)

| 修复 | 说明 |
|------|------|
| `File_readAll` 函数名冲突 | 静态方法 `File_readAll(path)` 与实例方法 `File_readAll(LemonFile*)` 冲突，将实例方法重命名为 `LemonFile_readAll` |
| `Array`/`Map` 静态方法代码生成 | `Array.size(arr)` 生成 `Array_size(Array, arr)` 而非 `LemonArray_size(arr)`，新增 `gen_builtin_type_method_call` 方法 |
| 字段类型推断 | `infer_class_from_expr` 扩展支持 `FieldAccess` 字段类型查找，修复 `this.tokens.get()` 生成 `Parser_get` 的问题 |
| `String.join` 内建方法 | 新增 `join` 作为 String 内建方法，C 运行时实现 `String_join` |
| `Array.push` 内建方法 | 新增 `push` 作为 Array 内建方法（`add` 的别名），C 运行时实现 `LemonArray_push` |

### 优化器 (optimizer.rs)

| 修复 | 说明 |
|------|------|
| 循环变量常量传播 | `while`/`for` 循环前收集被赋值变量并从 `constant_env` 移除，避免将循环变量替换为常量 |

### 词法分析器 (lexer.rs)

| 修复 | 说明 |
|------|------|
| `\0` 转义序列 | 添加对 `\0` 转义的处理 |

## VS Code 扩展 (vscode-lemon) 修复

### 诊断 (diagnostics.ts)

| 修复 | 说明 |
|------|------|
| 移除虚假语义检查 | 删除 `checkSemantics` 方法（裸方法调用、未定义变量、变量/函数重声明检查），这些检查产生大量误报，语义分析应由编译器完成 |
| 字符串转义处理 | 用连续反斜杠计数替代 `prevChar !== '\\'`，正确处理 `\\"` 等转义序列 |
| 未闭合字符串误报 | 添加 `!inBlockComment` 条件，避免块注释中误报未闭合字符串 |

### 代码补全 (completion.ts)

| 更新 | 说明 |
|------|------|
| 内置类补全 | 替换 C 函数列表为 Lemon 内置类（System, String, Array, Map, StringBuilder, File, Character） |
| `System.` 成员补全 | printf, println, exit, currentTimeMillis |
| `Array.` 成员补全 | size, add, push, get, set, remove, clear, contains |
| `Map.` 成员补全 | size, put, get, remove, containsKey, clear |
| String 静态方法补全 | intToString, longToString, doubleToString, join |
| String 实例方法补全 | 新增 startsWith, endsWith, contains, split, charAt, isEmpty |
