# v1.8.0 Changelog

## [1.8.0] - 2026-05-23

### Embedded VM Runtime (A.1)

Major refactoring of the Lemon VM from a standalone process (`lemonvm`) into an embeddable library (`LeVM`) that can be embedded into native executables for AOT+JIT hybrid execution.

#### LeVM Library Refactoring (A.1.1)

- **`LeVM` struct**: Replaced global-state VM with an instance-based `LeVM` struct, supporting multiple concurrent VM instances
- **`LeVM::from_bytes()`**: Create a VM directly from in-memory `.lmb` bytecode data (for embedded use)
- **`LeVM::call()`**: Call a VM function by index with arguments — primary interface for native→VM calls
- **`LeVM::call_by_name()`**: Call a VM function by name
- **`LeVM::find_function()`**: Look up a function index by name
- **`LeVM::register_native()`**: Register a native function callable from bytecode
- **`LeVM::reset()`**: Reset VM state while keeping the module and registered natives
- **`LeVM::set_jit_threshold()`**: Configure hot-spot detection threshold
- **`VM` type alias**: `pub type VM = LeVM` for backward compatibility
- **`#[repr(C)]` on `VMValue`/`VMObject`**: Ensures FFI-safe memory layout

#### C FFI Interface (A.1.2-5)

New `src/jit/ffi.rs` module providing C-compatible functions for native↔VM interop:

| Function | Description |
|----------|-------------|
| `le_vm_create(data, size)` | Create LeVM from embedded .lmb bytecode |
| `le_vm_destroy(vm)` | Destroy LeVM and free memory |
| `le_vm_call(vm, func_idx, args, argc)` | Call VM function by index |
| `le_vm_call_by_name(vm, name, args, argc)` | Call VM function by name |
| `le_vm_register_native(vm, name, func)` | Register native function |
| `le_vm_find_function(vm, name)` | Find function index by name |
| `le_vm_set_jit_threshold(vm, threshold)` | Set JIT hot-spot threshold |
| `le_vm_reset(vm)` | Reset VM state |
| `le_vm_result_to_int(result)` | Extract integer from result |
| `le_vm_result_to_float(result)` | Extract float from result |
| `le_vm_result_free(result)` | Free boxed result |

#### Native Function Registration (A.1.5)

- **`LeNativeFunc` type**: Changed to `extern "C" fn(args: *const VMValue, argc: usize) -> VMValue` for C calling convention compatibility
- **`CallNative(u32)` bytecode instruction**: New instruction that calls a registered native function by string pool index
- **Serialization support**: `CallNative` has opcode `0x46` with a u32 name index operand

#### Embedded .lmb Data Section (A.1.10)

- **`PeLinker::add_embedded_lmb()`**: Embeds `.lmb` bytecode as a custom PE section
- **Exported symbols**: `_lmb_data_start` (pointer to bytecode) and `_lmb_data_size` (bytecode size in .rdata)
- **Section characteristics**: `.lmb` section uses `IMAGE_SCN_CNT_INITIALIZED_DATA | IMAGE_SCN_MEM_READ`
- **Section name map**: Updated to recognize `.lmb` sections during COFF merging

#### Bug Fixes

- **`from_bytes()` compilation error**: Fixed by using `Cursor<&[u8]>` to satisfy `Read` trait, and `.map_err()` for error type conversion
- **`is_truthy()` missing pattern**: Added `VMValue::Object(_)` branch returning `true`
- **FFI-safe warnings**: Added `#[repr(C)]` to `VMValue` and `VMObject` enums
