# v2.3.0 Changelog

## [2.3.0] - 2026-05-23

### Known Issues Fix Round 1

Critical bug fixes and code quality improvements addressing the most impactful known issues from the project handover document.

#### VM Hardcoded Fixes (A.4.1-5)

- **Cast instruction**: Now performs actual type conversion (Int↔Float↔Bool↔String) instead of pass-through
- **InstanceOf instruction**: Checks actual value type (primitives by variant, objects by class_idx lookup) instead of always returning `true`
- **TypeId instruction**: Returns type-specific IDs (Null=0, Int=1, Float=2, Bool=3, String=4, Ptr=5, Array=6, Map=7, Object=100+class_idx) instead of always `0`
- **Lt/Gt/Le/Ge**: Now support mixed Int/Float comparisons (e.g., `3 < 4.5` works correctly)

#### CCodeGen exprIsStringType Unification

- **Problem**: Method names that return strings were hardcoded in 4 separate places with inconsistent lists
- **Solution**: Created two unified collections:
  - `stringReturningMethods`: 22 method names (String methods + CCodeGen internal methods)
  - `stringReturningFunctions`: 18 function names (String_*, TokenKind_*, Character_*)
- **New helpers**: `isStringReturningMethod(name)` and `isStringReturningFunction(name)`
- **Result**: Single source of truth — adding a new string-returning method only requires updating one list

#### LemonMap Rehash: Recursive → Iterative

- **Problem**: `LemonMap_put` called itself recursively during rehash, risking stack overflow with large maps
- **Solution**: Replaced recursive call with inline iterative linear probing insertion during rehash
- **Impact**: No more stack overflow risk; rehash is now O(n) with constant stack depth

#### Root Directory Cleanup

- **Deleted 17 .c files**: AST.c, Span.c, TokenKind.c, test_*.c, EnumTest.c, etc.
- **Updated .gitignore**: Added `*.c`, `*.asm`, `*.out`, `*.log`, `debug.gdb`, `*_err.txt`, `*_out.txt`
