这是一个很有野心的语言设计目标，在“底层控制、面向对象、低开销、完善GC”这几个维度之间确实存在经典矛盾。我们先把核心约束拆开来看：

## 一、目标定位的矛盾点

1. **偏底层（如C）** → 手动内存管理、无运行时、无GC、数据布局可控
2. **Java的面向对象** → 动态分派、引用语义、继承、多态
3. **性能开销足够节约** → GC和对象模型不能太重
4. **垃圾回收机制完善** → 必须有运行时、GC、写屏障等

这三者本质上会互相拉扯。**“像C一样底层”和“完善GC”通常不可兼得**，除非你重新定义“底层”。

## 二、可行的折中方向（不是答案，是选项）

### 方向A：价值语义 + 可选GC（类似Swift + 增强版Rust）
- 对象默认是**值类型**（栈上），用指针/引用来实现多态
- GC仅用于**托管堆上的引用对象**
- 提供手动内存管理（如`defer`、`arena`）
- **代价**：程序员必须区分值/引用类型

### 方向B：区域/世代GC + 无写屏障（实验性）
- 对象按区域分配，整区域回收
- 避免逐对象追踪的开销
- 类C的内存布局 + 编译期GC提示
- **代表性**：类似Cyclone、早期Singularity

### 方向C：编译期对象生命周期分析（Rust路线但加GC）
- 大部分对象可静态确定生命周期（无GC）
- 仅在必要处启用GC
- 对程序员暴露可选GC

## 三、语言特性草稿（讨论层）

| 特性 | 建议设计 | 原因 |
|------|----------|------|
| 内存默认 | 栈上值类型 | 开销低 |
| 对象 | 引用类型（可空） | OOP需要 |
| 继承 | 单继承 + 接口 | 避免复杂虚表 |
| GC | 非追踪式（如引用计数 + 周期检测） | 延迟可控，适合底层 |
| 并发GC | 暂停可预测，不依赖写屏障 | 降低开销 |
| 数组/容器 | 类型化、扁平存储 | 缓存友好 |
| FFI | 零开销C互操作 | “像C一样”的关键 |

5. **是否借鉴Rust的借用检查器但放松约束？**

## 三、三个设计草案（直接可用）

### 方案1：极致性能（游戏、高频交易风格）

**定位：C + 简单对象系统 + 辅助GC**

| 项目 | 决策 |
|------|------|
| 对象默认 | 值类型（栈） |
| 堆对象 | `class` 关键字，必须显式分配 |
| 多态 | 接口 + 泛型（无继承） |
| GC | 引用计数 + 循环检测器（后台线程） |
| 虚表开销 | 接口表（每对象一个指针） |
| 内存布局 | 完全可控（`@pack`, `@align`） |
| 暂停时间 | < 1ms |
| 适用场景 | 游戏、实时系统、嵌入式高级语言 |

**优点**：很贴合底层、开销极低  
**缺点**：不是完整Java风格OOP，没有继承复用  

---

### 方案2：平衡型（系统工具、数据库、网络服务）

**定位：Rust内存风格 + 可选GC + 类Java语法**

| 项目 | 决策 |
|------|------|
| 对象默认 | 栈，可提升为GC对象 |
| 继承 | 单继承 + 接口 |
| GC | 分代非移动GC（无写屏障） |
| 手动内存 | `@arena`, `@manual(free)` |
| 多态 | 虚方法表（单继承链） |
| 对象头 | 8字节（GC标志 + 类型ID） |
| 暂停时间 | 5–20ms（可配置） |
| C互调 | 直接声明外部函数 |

**优点**：开发体验接近Java，性能接近C++  
**缺点**：GC仍是非零开销，写代码需要区分值/引用  

---

### 方案3：类Java但更底层（替换部分Java中间件场景）

**定位：Java语法子集 + 显式内存控制 + 改进GC**

| 项目 | 决策 |
|------|------|
| 语法 | 几乎就是Java 8（去反射） |
| 所有对象 | GC托管（统一堆） |
| 栈对象 | 不支持（但有值类型`record`） |
| GC | 低暂停实时GC（Shenandoah风格） |
| 内存布局 | 程序员可控字段顺序 |
| 无虚表优化 | SEALED类 / final方法 |
| 运行时可裁剪 | 不需要VM，直接编译到Native |

**优点**：Java程序员易上手  
**缺点**：依然有GC开销，不算“真底层”

## 二、内存布局设计（核心）

### 2.1 对象头（最小化，8字节）

```c
// 任何GC对象的开头（栈对象无此头）
struct ObjectHeader {
    uint32_t ref_count;   // 引用计数（4字节）
    uint8_t  type_id;     // 类型ID，用于接口分发（1字节）
    uint8_t  flags;       // GC标志、是否被锁定等（1字节）
    uint16_t padding;     // 对齐（2字节）
};  // 总计8字节
```

**对比Java对象头（12-16字节 + 对齐）** 节约了 4-8 字节。

### 2.2 类实例布局（单继承 + 接口）

```c
// 示例类
class Animal {
    int age;
    virtual void speak();
}

class Dog extends Animal implements Runnable, Serializable {
    int legs;
    void speak() override;
    void run() override;
}

// 内存布局（64位系统）
struct Dog_Instance {
    // 1. 对象头（8字节）
    ObjectHeader header;
    
    // 2. 虚表指针（8字节）
    void* vtable;
    
    // 3. 接口表指针数组（每个接口一个）
    void* itable_Runnable;    // 8字节
    void* itable_Serializable; // 8字节
    
    // 4. 父类字段
    int age;                   // 4字节
    int padding1;              // 4字节对齐
    
    // 5. 自身字段
    int legs;                  // 4字节
    int padding2;              // 4字节对齐
    
    // 总大小: 8 + 8 + 16 + 8 + 8 = 48字节
};
```

**对比Java相同结构（约64-80字节）**，节约 20-30%。

### 2.3 栈上的值类型（无多态）

```c
// 值类型（struct），不支持继承/接口
struct Point {
    int x, y;
};

// 使用栈分配，无对象头，直接内嵌
Point p;  // 8字节，无GC
```

## 三、虚方法调用开销（精确控制）

### 3.1 单继承虚调用（与C++相当）

```c
// 编译前
animal.speak();

// 编译后（伪汇编）
mov rdi, [animal]        // 加载对象地址
mov rax, [rdi + 8]       // 加载vtable（跳过对象头）
call [rax + 0]           // 第一个虚函数
```

**开销**：2次内存访问 + 1次间接调用 ≈ 2-3ns（缓存命中）

### 3.2 接口调用（稍高，但可控）

```c
// 编译前
((Runnable)dog).run();

// 编译后
mov rdi, [dog]                // 加载对象
mov rax, [rdi + 16]           // 加载Runnable接口表
call [rax + 0]                // 调用run方法
```

**开销**：同虚调用，但在多重继承场景需要查找接口表位置（编译期固定）。

### 3.3 接口调用的优化（关键设计）

```java
// 场景：频繁调用同一接口
Runnable r = dog;
for (int i = 0; i < 1000000; i++) {
    r.run();  // 每次调用的接口表位置都相同
}
```

**优化**：接口表指针在编译期固定偏移，无查找开销。

## 四、与Java OOP的关键差异（必须明确）

### 4.1 没有统一的`Object`根类

```c
// Java思维（不支持）
Object obj = new Dog();  // ❌ 没有万能根类

// 方案1的替代：使用接口
AnyRef obj = new Dog();   // ✅ 特殊的any类型，仅用于指针传递
```

**原因**：`Object`需要大量公共方法（`hashCode`, `equals`, `toString`），会强制每个对象携带额外元数据。

### 4.2 没有运行时类型判断（`instanceof`）

```c
// Java
if (obj instanceof Dog) { ... }

// 方案1替代：类型ID枚举
if (obj->header.type_id == TYPE_DOG) { ... }
```

类型ID在编译期分配，判断极快（1字节比较），但只支持精确匹配（无法判断继承关系）。

### 4.3 没有自动的`finalize`

- 析构由程序员调用或引用计数归零时触发
- 不支持Java的`finalize`（不可预测，性能差）

### 4.4 `synchronized`关键字不存在

- 锁需要对象头中的元数据（增加开销）
- 替代方案：显式的`mutex`库（栈上分配）

## 二、多继承设计（务实版）

### 2.1 支持范围

```c
// 允许：一个基类 + 多个抽象类（接口）
class A { ... }                    // 实现继承
abstract class B { virtual void f(); }  // 抽象类
interface C { void g(); }          // 接口

class D extends A implements B, C {
    void f() override;
    void g() override;
}
```

**不允许：**
- 多实现继承（`extends A, B`）
- 钻石问题自动消解（需手动指定）

### 2.2 内存布局（多继承版本）

```c
// 类D的实例布局
struct D_Instance {
    // 1. 对象头（12字节，原8+4）
    uint32_t ref_count;
    void* type_info;        // 指向反射元数据（4/8字节）
    uint16_t flags;
    uint16_t padding;
    
    // 2. 主虚表指针（基类A的虚方法）
    void* vtable_A;
    
    // 3. 抽象类B的虚表指针
    void* vtable_B;
    
    // 4. 接口C的虚表指针
    void* vtable_C;
    
    // 5. 基类A的字段
    ...A_fields...
    
    // 6. 抽象类B没有字段（纯抽象）
    
    // 7. 接口C没有字段
    
    // 8. 类D自身字段
    ...D_fields...
};
```

**对比单继承版本**：多了 `type_info`（4/8字节）+ 额外虚表指针（每个父类/接口一个）。

### 2.3 菱形问题处理（显式消歧义）

```c
interface Flyable {
    void fly();
}

interface Drivable {
    void fly();  // 同名方法
}

class FlyingCar implements Flyable, Drivable {
    // 必须显式实现两个版本

}
```

## 三、反射设计（轻量级）

### 3.1 设计原则

- **按需启用**：`@reflectable` 注解
- **元数据只读**：存储在单独数据段（不加载到堆）
- **无运行时修改**（不支持`setAccessible`）
- **反射信息不包含方法体**（只有签名）

### 3.2 反射信息结构（静态存储）

```c
// 编译时生成的元数据（存储在只读段）
struct TypeMetadata {
    const char* name;
    uint32_t size;
    uint16_t field_count;
    uint16_t method_count;
    FieldInfo* fields;      // 字段信息数组
    MethodInfo* methods;    // 方法信息数组
    TypeInfo* interfaces;   // 实现的接口
    TypeInfo* superclass;   // 父类
};

struct FieldInfo {
    const char* name;
    uint32_t offset;        // 字段在对象中的偏移
    TypeInfo* type;
    uint16_t flags;         // public/private/static
};

struct MethodInfo {
    const char* name;
    const char* signature;   // 类型签名
    void* function_ptr;      // 方法入口地址
    uint16_t flags;
};
```

### 3.3 运行时反射API（极小实现）

```c
// 获取类型信息
TypeInfo* type_of(void* obj);  // 从对象头的type_info获取

// 反射查询（编译时生成代码）
FieldInfo* get_field(TypeInfo* type, const char* name);
MethodInfo* get_method(TypeInfo* type, const char* name);

// 动态调用（无装箱）
void* invoke_method(MethodInfo* method, void* obj, void* args[]);

// 遍历字段
void iterate_fields(void* obj, void (*callback)(FieldInfo* field, void* field_ptr));
```

### 3.4 使用示例

```c
@reflectable
class Person {
    public String name;
    private int age;
    
    public void sayHello() {
        printf("Hello, I'm %s", name);
    }
}

// 反射使用
Person* p = new Person("Alice", 30);
TypeInfo* t = type_of(p);

// 按名称访问字段
FieldInfo* name_field = get_field(t, "name");
String* name_ptr = (String*)((char*)p + name_field->offset);
printf("%s", *name_ptr);  // 输出Alice

// 动态调用方法
MethodInfo* method = get_method(t, "sayHello");
invoke_method(method, p, NULL);  // 输出Hello...
```

### 3.5 性能开销

| 操作 | 开销 | 对比Java |
|------|------|----------|
| `type_of()` | 1次内存访问 | 相当 |
| `get_field()` | O(1)哈希查找 | 更快（无非维护软缓存） |
| 字段读取 | 额外偏移计算（编译时已知可内联） | 相当 |
| 动态调用 | 间接跳转 + 参数拷贝 | 略低（无异常检查） |
| 内存占用（反射） | 每个类200-500字节元数据 | Java是数KB |

**关键优化**：
- 反射信息在链接时可剥离（`strip --remove-section=.reflect`）
- 生产环境可彻底禁用（编译标志 `-no-reflect`）

### 4.1 基础对象头（12字节）

```c
struct ObjectHeader {
```

### 4.2 完整类实例（多继承 + 反射）

```c
@reflectable
class Employee extends Person implements Runnable, Serializable {
    int salary;
    void run() override;
}

struct Employee_Instance {
    // 对象头（16字节）
    ObjectHeader header;

    void* vtable_Person;       // 8字节
    void* vtable_Runnable;     // 8字节
```

## 七、实际代码示例（完整功能）

```c
@reflectable
interface Drawable {
    void draw();
}

@reflectable
interface Scalable {
    void scale(float factor);
}

@reflectable
abstract class Shape {
    String color;
    
    virtual float area() = 0;  // 纯虚
}

@reflectable
class Circle extends Shape implements Drawable, Scalable {
    float radius;
    
    override float area() {
        return 3.14f * radius * radius;
    }
    
    override void draw() {
        printf("Drawing %s circle", color);
    }
    
    override void scale(float factor) {
        radius *= factor;
    }
}

// 反射使用
void introspect(void* obj) {
    TypeInfo* t = type_of(obj);
    printf("Type: %s\n", t->name);
    printf("Size: %d bytes\n", t->size);
    printf("Fields:\n");
    for (int i = 0; i < t->field_count; i++) {
        printf("  %s : %s (offset %d)\n", 
               t->fields[i].name,
               t->fields[i].type->name,
               t->fields[i].offset);
    }
}

// 序列化框架（利用反射）
void serialize(void* obj, Stream* s) {
    TypeInfo* t = type_of(obj);
    for (int i = 0; i < t->field_count; i++) {
        if (t->fields[i].flags & PUBLIC) {
            void* field_ptr = (char*)obj + t->fields[i].offset;
            write_field(s, &t->fields[i], field_ptr);
        }
    }
}
```

| 8 | `<` `>` `<=` `>=` | 左 |
| 9 | `<<` `>>` | 左 |
| 10 | `+` `-` | 左 |
| 11 | `*` `/` `%` | 左 |
| 12 | `!` `~` `++` `--` `+` `-` `*` `&` | 右 |
| 13 | `(` `)` `[` `]` `.` `->` | 左 |

## 2. 顶层结构

```
<translation_unit>    ::= { <declaration> }

<declaration>         ::= <class_decl>
                        | <interface_decl>
                        | <function_decl>
                        | <variable_decl> ';'
                        | <import_decl>
                        | <package_decl>
                        | <extern_decl>
```

## 3. 包与导入

```
<package_decl>        ::= 'package' <qualified_ident> ';'

<import_decl>         ::= 'import' <qualified_ident> [ 'as' <identifier> ] ';'
                        | 'import' '*' ';'

<qualified_ident>     ::= <identifier> { '.' <identifier> }
```

## 4. 类声明

```
<class_decl>          ::= [ <class_modifier> ] 'class' <identifier> 
                          [ <type_params> ]
                          [ 'extends' <type_ref> ]
                          [ 'implements' <type_list> ]
                          '{' { <class_member> } '}'

<class_modifier>      ::= 'public' | 'private' | 'abstract' | 'final'
                        | 'reflectable'

<type_params>         ::= '<' <type_param> { ',' <type_param> } '>'

<type_param>          ::= <identifier> [ 'extends' <type_ref> ]

<type_list>           ::= <type_ref> { ',' <type_ref> }

<class_member>        ::= <field_decl>
                        | <method_decl>
                        | <constructor_decl>
                        | <destructor_decl>
                        | <static_initializer>
                        | <class_decl>          // 内部类
                        | <interface_decl>      // 内部接口
```

---

## 5. 接口声明

```
<interface_decl>      ::= [ 'public' | 'private' ] 'interface' <identifier>
                          [ <type_params> ]
                          [ 'extends' <type_list> ]    // 多继承接口
                          '{' { <interface_member> } '}'

<interface_member>    ::= <method_signature> ';'
                        | <field_decl>           // 默认为 static final
                        | <class_decl>
                        | <interface_decl>

<method_signature>    ::= [ 'public' | 'private' ] <type_ref> <identifier>
                          '(' [ <param_list> ] ')' [ 'throws' <type_list> ]
```

---

## 6. 字段声明

```
<field_decl>          ::= [ <field_modifier> ] <type_ref> <variable_declarators> ';'

<field_modifier>      ::= 'public' | 'private' | 'static' | 'final'

<variable_declarators> ::= <variable_declarator> { ',' <variable_declarator> }

<variable_declarator> ::= <identifier> [ '=' <expression> ]
```

## 7. 方法声明

```
<method_decl>         ::= [ <method_modifier> ] <function_decl>

<method_modifier>     ::= 'public' | 'private' | 'static'
                        | 'virtual' | 'override' | 'final' | 'abstract'

<function_decl>       ::= <type_ref> <identifier> '(' [ <param_list> ] ')'
                          [ 'throws' <type_list> ]
                          ( ';' | <block> )

<param_list>          ::= <param> { ',' <param> }

<param>               ::= <type_ref> <identifier> [ '=' <expression> ]
```

## 8. 构造函数与析构函数

```
<constructor_decl>    ::= [ <ctor_modifier> ] <identifier> '(' [ <param_list> ] ')'
                          [ 'throws' <type_list> ]
                          <block>

<ctor_modifier>       ::= 'public' | 'private'

<destructor_decl>     ::= '~' <identifier> '(' ')' <block>

<static_initializer>  ::= 'static' <block>
```

## 9. 类型系统

```
<type_ref>            ::= <primitive_type>
                        | <qualified_ident> [ '<' <type_args> '>' ]
                        | <type_ref> '[' ']'       // 数组类型
                        | '(*' <type_ref> ')' '(' [ <type_list> ] ')'  // 函数指针

<primitive_type>      ::= 'void' | 'bool' | 'byte' | 'char' | 'short'
                        | 'int' | 'long' | 'float' | 'double'

<type_args>           ::= <type_ref> { ',' <type_ref> }

<type_list>           ::= <type_ref> { ',' <type_ref> }
```

## 10. 语句

```
<statement>           ::= <block>
                        | <expression_statement>
                        | <if_statement>
                        | <for_statement>
                        | <while_statement>
                        | <return_statement>
                        | <break_statement>
                        | <continue_statement>
                        | <try_statement>
                        | <variable_decl> ';'

<block>               ::= '{' { <statement> } '}'

<expression_statement> ::= <expression> ';'

<if_statement>        ::= 'if' '(' <expression> ')' <statement>
                          [ 'else' <statement> ]

<for_statement>       ::= 'for' '(' [ <expression> ] ';' [ <expression> ] ';' [ <expression> ] ')'
                          <statement>
                        | 'for' '(' <variable_decl> ';' [ <expression> ] ';' [ <expression> ] ')'
                          <statement>

<while_statement>     ::= 'while' '(' <expression> ')' <statement>

<return_statement>    ::= 'return' [ <expression> ] ';'

<break_statement>     ::= 'break' ';'

<continue_statement>  ::= 'continue' ';'

<try_statement>       ::= 'try' <block>
                          ( 'catch' '(' <type_ref> <identifier> ')' <block> )+
                          [ 'finally' <block> ]
```

## 11. 表达式

```
<expression>          ::= <assignment_expr>

<assignment_expr>     ::= <conditional_expr>
                        | <unary_expr> <assignment_operator> <assignment_expr>

<assignment_operator> ::= '=' | '+=' | '-=' | '*=' | '/=' | '%=' 
                        | '&=' | '|=' | '^=' | '<<=' | '>>='

<conditional_expr>    ::= <logical_or_expr> [ '?' <expression> ':' <expression> ]

<logical_or_expr>     ::= <logical_and_expr> { '||' <logical_and_expr> }

<logical_and_expr>    ::= <inclusive_or_expr> { '&&' <inclusive_or_expr> }

<inclusive_or_expr>   ::= <exclusive_or_expr> { '|' <exclusive_or_expr> }

<exclusive_or_expr>   ::= <and_expr> { '^' <and_expr> }

<and_expr>            ::= <equality_expr> { '&' <equality_expr> }

<equality_expr>       ::= <relational_expr> { ('==' | '!=') <relational_expr> }

<relational_expr>     ::= <shift_expr> { ('<' | '>' | '<=' | '>=') <shift_expr> }
                        | <relational_expr> 'instanceof' <type_ref>

<shift_expr>          ::= <additive_expr> { ('<<' | '>>') <additive_expr> }

<additive_expr>       ::= <multiplicative_expr> { ('+' | '-') <multiplicative_expr> }

<multiplicative_expr> ::= <unary_expr> { ('*' | '/' | '%') <unary_expr> }

<unary_expr>          ::= <postfix_expr>
                        | ('++' | '--' | '+' | '-' | '!' | '~' | '*' | '&') <unary_expr>
                        | 'new' <type_ref> [ '(' [ <arg_list> ] ')' ]
                        | 'delete' <unary_expr>
                        | '(' <type_ref> ')' <unary_expr>   // 强制类型转换
                        | 'sizeof' '(' <type_ref> ')'
                        | 'typeid' '(' <expression> ')'

<postfix_expr>        ::= <primary_expr>
                        | <postfix_expr> '[' <expression> ']'
                        | <postfix_expr> '(' [ <arg_list> ] ')'
                        | <postfix_expr> '.' <identifier>
                        | <postfix_expr> '->' <identifier>
                        | <postfix_expr> '++'
                        | <postfix_expr> '--'

<primary_expr>        ::= <literal>
                        | 'this'
                        | 'super'
                        | 'null'
                        | '(' <expression> ')'
                        | <qualified_ident> [ '<' <type_args> '>' ]
                        | <lambda_expr>

<lambda_expr>         ::= '(' [ <param_list> ] ')' '->' ( <expression> | <block> )

<arg_list>            ::= <expression> { ',' <expression> }

<literal>             ::= <integer_literal>
                        | <float_literal>
                        | <string_literal>
                        | 'true'
                        | 'false'
                        | 'null'
```

```c
package com.example;

import java.util.*;

@reflectable
public abstract class Animal<T> {
    private String name;
    protected int age;
    
    public Animal(String name) {
        this.name = name;
        this.age = 0;
    }
    
    public virtual String speak() {
        return "???";
    }
    
    public final String getName() {
        return this.name;
    }
    
    public abstract T getData();
}

public class Dog extends Animal<int[]> implements Runnable, Cloneable {
    public static final int MAX_LEGS = 4;
    private int legs;
    
    public Dog(String name, int legs) {
        super(name);
        this.legs = legs;
    }
    
    @override
    public String speak() {
        return "Woof! I have " + this.legs + " legs";
    }
    
    @override
    public int[] getData() {
        return new int[] { this.legs, Dog.MAX_LEGS };
    }
    
    @override
    public void run() {
        printf("%s is running\n", getName());
    }
    
    public static Dog createDefault() {
        Dog d = new Dog("Buddy", 4);
        return d;
    }
    
    ~Dog() {
        printf("Goodbye %s\n", getName());
    }
}

void main() {
    Dog* d = Dog.createDefault();
    
    // 多态
    Animal<int[]>* a = (Animal<int[]>*)d;
    printf("%s\n", a->speak());
    
    // 接口调用
    Runnable* r = (Runnable*)d;
    r->run();
    
    // 类型判断
    if (d instanceof Animal<int[]>) {
        printf("Is an animal\n");
    }
    
    // 静态调用
    int max = Dog.MAX_LEGS;
    
    // 迭代
    for (int i = 0; i < 3; i++) {
        printf("Count: %d\n", i);
    }
    
    // Lambda
    int(*add)(int, int) = (int x, int y) -> x + y;
    printf("2+3=%d\n", add(2, 3));
    
    delete d;
}
```

## 13. 歧义点消解规则

| 场景 | 处理规则 |
|------|----------|
| `<` 是泛型还是小于号 | 词法层面，在`<type_args>`上下文中解析为泛型 |
| `>>` 是右移还是闭泛型 | 词法扫描时贪婪匹配，语义阶段修正 |
| `A<B,C>` 是泛型还是逗号运算符 | 如果`A`是类型名，解析为泛型 |
| `*` 是乘法还是解引用 | 根据上下文：`*x`是解引用，`a*b`是乘法 |
| 菱形问题 | 编译报错，要求显式使用`InterfaceName::method` |

# 虚表布局设计 (V1.0)

## 一、核心数据结构

### 1.1 对象头 (16字节)

```
┌─────────────────────────────────────────────────────────────┐
│                        对象头 (16 bytes)                      │
├─────────────────┬─────────────────┬───────────────┬─────────┤
│   ref_count     │   type_info     │     flags     │ padding │
│   (4 bytes)     │   (8 bytes)     │   (2 bytes)   │ (2 bytes)│
├─────────────────┼─────────────────┼───────────────┼─────────┤
│ 引用计数         │ 反射元数据指针    │ GC/锁标志      │ 对齐用   │
└─────────────────┴─────────────────┴───────────────┴─────────┘
```

### 1.2 虚表结构 (每个类一张)

```c
struct VTable {
    void* (*destructor)(void*);     // 析构函数 (offset 0)
    void* (*clone)(void*);          // 克隆函数 (offset 8)
    void* methods[];                 // 虚方法指针数组 (offset 16)
};

// 实际内存布局
// offset 0:  destructor
// offset 8:  clone
// offset 16: method 0 (第一个虚方法)
// offset 24: method 1
// ...
```

### 1.3 接口表结构 (每个接口一张)

```c
struct ITable {
    void* (*method0)(void*, ...);    // 接口方法0
    void* (*method1)(void*, ...);    // 接口方法1
    // ...
};
```

## 四、接口转换 (向上转型)

### 4.1 转换操作

```c
Dog* dog = new Dog();

// 转换为接口类型
Runnable* r = (Runnable*)dog;           // 编译器调整指针!
Serializable* s = (Serializable*)dog;

// 编译器生成的调整代码
// r = dog + DOG_OFFSET_ITABLE_RUNNABLE - sizeof(ObjectHeader)
// s = dog + DOG_OFFSET_ITABLE_SERIALIZABLE - sizeof(ObjectHeader)
```

### 4.2 内存指针布局

```
原始 dog 指针: 0x1000 (指向对象头)
                    │
                    ▼
        ┌───────────────────────┐
0x1000  │  对象头 (16 bytes)     │
        ├───────────────────────┤
0x1010  │  vtable_Animal (8)    │ ← dog + 16
        ├───────────────────────┤
0x1018  │  itable_Runnable (8)  │ ← (Runnable*)dog 实际指向这里 (0x1018)
        ├───────────────────────┤
0x1020  │  itable_Serializable(8)│ ← (Serializable*)dog 指向这里 (0x1020)
        ├───────────────────────┤
0x1028  │  Animal.age (4)       │
        └───────────────────────┘

// 关键: 接口指针并不指向对象头，而是指向接口表指针
```

### 4.3 接口方法调用

```c
Runnable* r = (Runnable*)dog;
r->run();

// 生成的汇编 (x86-64)
mov rdi, [r]           // rdi = itable_Runnable指针 (0x1018)
mov rax, [rdi]         // rax = itable_Runnable[0] (run函数地址)
call rax               // 调用 run

// 注意: Dog_run 需要接收原始对象指针
// 约定: 第一个参数始终是原始对象指针 (通过寄存器传递)
```

### 4.4 接口方法实现约定

```c
// 编译器生成的 Dog_run 实现 (伪代码)
void Dog_run(void* obj_ptr) {
    // obj_ptr 是从接口表调用时传入的原始对象指针
    // 但由于接口指针偏移了，需要回退到对象头
    
    // 计算原始对象头位置
    Dog* dog = (Dog*)((char*)obj_ptr - DOG_OFFSET_ITABLE_RUNNABLE);
    
    // 执行实际逻辑
    printf("%s is running\n", dog->getName());
}
```

## 五、多接口继承 (菱形问题处理)

### 5.1 场景定义

```c
interface Flyable {
    void fly();
}

interface Drivable {
    void fly();  // 同名方法!
}

class FlyingCar implements Flyable, Drivable {
    // 必须显式实现两个版本
```

## 六、虚表生成算法

### 6.1 单继承虚表生成

```
输入: 类 C，父类 P，C的方法列表 M
输出: C的虚表 V

算法:
1. V = 复制 P的虚表
2. For each method m in M:
   if m is virtual:
       if m overrides method in P:
           替换 V 中对应槽位
       else:
           在 V 末尾追加新槽位
3. 填充 destructor 和 clone 槽位
```

### 6.2 接口表生成

```
输入: 类 C，实现的接口列表 I[]
输出: 每个接口的接口表 IT[]

算法:
For each interface iface in I:
    IT[iface] = 新建空表
    For each method m in iface.methods:
        if C has implementation for m:
            IT[iface].append(C.implementation_of(m))
        else if C has default from interface:
            IT[iface].append(iface.default_method(m))
        else:
            compile_error("missing implementation")
```

### 6.3 布局决策树

```
开始布局类C
    │
    ├─ C有父类吗?
    │   ├─ 有 → 继承父类虚表布局，添加额外虚表指针
    │   └─ 无 → 创建新的虚表区
    │
    ├─ C实现接口吗?
    │   ├─ 有 → 为每个接口分配接口表槽位
    │   └─ 无 → 跳过
    │
    └─ 分配字段偏移
        ├─ 父类字段在前
        ├─ 自身字段在后
        └─ 对齐到最大字段对齐要求
```

# GC实现伪代码 (V1.0)

## 一、核心数据结构

### 1.1 对象头定义

```c
// gc.h
typedef struct ObjectHeader {
    // 引用计数 (原子操作，支持多线程)
    _Atomic uint32_t ref_count;
    
    // 类型信息指针 (反射用)
    TypeInfo* type_info;
    
    // GC标志位
    union {
        struct {
            uint16_t is_marked : 1;      // 标记清扫用
            uint16_t in_cycle : 1;       // 周期检测中
            uint16_t visited : 1;        // 图遍历已访问
            uint16_t on_stack : 1;       // 栈上临时对象
            uint16_t is_weak : 1;        // 弱引用标志
            uint16_t reserved : 11;
        };
        uint16_t flags;
    };
    
    // 对齐填充
    uint16_t padding;
} ObjectHeader;

// 获取对象头
#define HEADER(obj) ((ObjectHeader*)((char*)(obj) - sizeof(ObjectHeader)))

// 获取对象数据起始地址
#define DATA(header) ((void*)((char*)(header) + sizeof(ObjectHeader)))
```

### 1.2 周期检测节点

```c
// cycle_detector.h
typedef struct GCObjectNode {
    ObjectHeader* obj;              // 对象指针
    uint32_t ref_count;             // 快照时的引用计数
    uint32_t internal_refs;         // 内部引用数
    struct GCObjectNode* next;      // 链表next
    uint8_t color;                  // 颜色标记 (黑/灰/白)
} GCObjectNode;

// 颜色定义
#define COLOR_BLACK   0  // 根可达，保留
#define COLOR_GRAY    1  // 正在处理
#define COLOR_WHITE   2  // 疑似垃圾，可回收

// 全局周期检测器状态
typedef struct CycleDetector {
    GCObjectNode* candidates;       // 候选对象链表
    GCObjectNode* root_set;         // 根集快照
    pthread_mutex_t lock;           // 检测器锁
    pthread_t detector_thread;      // 后台线程
    volatile int running;           // 运行标志
    uint32_t scan_interval;         // 扫描间隔(ms)
    uint32_t max_scan_objects;      // 单次最大扫描数
} CycleDetector;
```

## 二、核心操作 API

### 2.1 对象分配

```c
// gc_alloc.c
void* gc_alloc(size_t size, TypeInfo* type) {
    // 计算总大小: header + data
    size_t total_size = sizeof(ObjectHeader) + size;
    
    // 分配内存
    ObjectHeader* header = (ObjectHeader*)calloc(1, total_size);
    if (!header) return NULL;
    
    // 初始化对象头
    header->ref_count = 1;           // 初始引用计数为1
    header->type_info = type;
    header->flags = 0;
    header->padding = 0;
    
    // 注册到周期检测器 (如果对象可能产生循环引用)
    if (type->may_have_cycles) {
        cycle_detector_register(header);
    }
    
    // 返回数据区指针
    return DATA(header);
}

// 支持手动管理的分配 (绕过GC)
void* gc_alloc_manual(size_t size, TypeInfo* type) {
    // 无引用计数，无周期检测，需手动delete
    size_t total_size = sizeof(ObjectHeader) + size;
    ObjectHeader* header = (ObjectHeader*)calloc(1, total_size);
    if (!header) return NULL;
    
    header->ref_count = 0;           // 引用计数为0表示不受GC管理
    header->type_info = type;
    header->flags = 0;
    
    return DATA(header);
}
```

### 2.2 引用计数操作

```c
// gc_refcount.c
void retain(void* obj) {
    if (!obj) return;
    ObjectHeader* header = HEADER(obj);
    
    // 不受GC管理的对象，不操作引用计数
    if (header->ref_count == 0) return;
    
    // 原子递增
    atomic_fetch_add(&header->ref_count, 1);
}

void release(void* obj) {
    if (!obj) return;
    ObjectHeader* header = HEADER(obj);
    
    // 不受GC管理的对象，直接忽略
    if (header->ref_count == 0) return;
    
    // 原子递减
    uint32_t old_count = atomic_fetch_sub(&header->ref_count, 1);
    
    // 如果引用计数变为0，回收对象
    if (old_count == 1) {
        // 先清理弱引用
        weak_ref_clear_target(header);
        
        // 调用析构函数
        if (header->type_info->destructor) {
            header->type_info->destructor(obj);
        }
        
        // 释放内存
        free(header);
    }
}
```

## 三、周期检测器实现

### 3.1 后台线程主循环

```c
// cycle_detector.c
void* cycle_detector_thread(void* arg) {
    CycleDetector* detector = (CycleDetector*)arg;
    
    while (detector->running) {
        // 等待扫描间隔
        usleep(detector->scan_interval * 1000);
        
        // 获取当前所有候选对象
        pthread_mutex_lock(&detector->lock);
        GCObjectNode* candidates = detector->candidates;
        detector->candidates = NULL;
        pthread_mutex_unlock(&detector->lock);
        
        if (!candidates) continue;
        
        // 执行周期检测
        detect_cycles(candidates);
        
        // 释放检测结果
        free_candidate_list(candidates);
    }
    
    return NULL;
}

// 启动周期检测器
void cycle_detector_start(CycleDetector* detector) {
    detector->running = 1;
    pthread_create(&detector->detector_thread, NULL, 
                   cycle_detector_thread, detector);
}
```

### 3.2 核心检测算法

```c
// 基于tricolor marking的周期检测
void detect_cycles(GCObjectNode* root_set) {
    // Phase 1: 标记根集 (黑色)
    mark_roots_black(root_set);
    
    // Phase 2: 计算快照引用计数
    compute_snapshot_refcounts(root_set);
    
    // Phase 3: 扫描白色对象
    scan_for_cycles(root_set);
    
    // Phase 4: 回收白色对象
    collect_white_objects(root_set);
}

void mark_roots_black(GCObjectNode* root_set) {
    GCObjectNode* node = root_set;
    while (node) {
        if (node->obj->ref_count > 0) {
            node->color = COLOR_BLACK;
            // 递归标记可达对象
            mark_reachable(node);
        } else {
            node->color = COLOR_WHITE;
        }
        node = node->next;
    }
}

void compute_snapshot_refcounts(GCObjectNode* root_set) {
    GCObjectNode* node = root_set;
    while (node) {
        // 保存当前引用计数快照
        node->ref_count = node->obj->ref_count;
        node->internal_refs = 0;
        node = node->next;
    }
    
    // 遍历所有引用关系，计算内部引用数
    node = root_set;
    while (node) {
        // 遍历对象的所有字段
        ObjectField* fields = node->obj->type_info->fields;
        for (int i = 0; fields[i].type; i++) {
            if (fields[i].type->is_gc_object) {
                void* field_ptr = (char*)DATA(node->obj) + fields[i].offset;
                void* target = *(void**)field_ptr;
                
                if (target) {
                    GCObjectNode* target_node = find_node(root_set, target);
                    if (target_node) {
                        // 这是一个内部引用
                        target_node->internal_refs++;
                    }
                }
            }
        }
        node = node->next;
    }
}

void scan_for_cycles(GCObjectNode* root_set) {
    GCObjectNode* node = root_set;
    while (node) {
        if (node->color == COLOR_WHITE) {
            // 疑似垃圾，检查是否真的形成环
            uint32_t external_refs = node->ref_count - node->internal_refs;
            
            if (external_refs == 0) {
                // 无外部引用，这个环可以回收
                mark_cycle_as_garbage(node);
            } else {
                // 有外部引用，保留
                node->color = COLOR_BLACK;
            }
        }
        node = node->next;
    }
}

void collect_white_objects(GCObjectNode* root_set) {
    GCObjectNode* node = root_set;
    while (node) {
        if (node->color == COLOR_WHITE) {
            // 回收对象
            ObjectHeader* obj = node->obj;
            
            // 通知弱引用
            weak_ref_clear_target(obj);
            
            // 调用析构函数
            if (obj->type_info->destructor) {
                obj->type_info->destructor(DATA(obj));
            }
            
            // 释放内存
            free(obj);
        }
        node = node->next;
    }
}
```

### 3.3 对象注册与注销

```c
void cycle_detector_register(ObjectHeader* obj) {
    // 只为可能产生循环引用的对象注册
    if (!obj->type_info->may_have_cycles) return;
    
    GCObjectNode* node = (GCObjectNode*)malloc(sizeof(GCObjectNode));
    node->obj = obj;
    node->color = COLOR_BLACK;
    node->next = NULL;
    
    pthread_mutex_lock(&global_detector.lock);
    node->next = global_detector.candidates;
    global_detector.candidates = node;
    pthread_mutex_unlock(&global_detector.lock);
}

void cycle_detector_unregister(ObjectHeader* obj) {
    pthread_mutex_lock(&global_detector.lock);
    
    GCObjectNode* prev = NULL;
    GCObjectNode* curr = global_detector.candidates;
    
    while (curr) {
        if (curr->obj == obj) {
            if (prev) {
                prev->next = curr->next;
            } else {
                global_detector.candidates = curr->next;
            }
            free(curr);
            break;
        }
        prev = curr;
        curr = curr->next;
    }
    
    pthread_mutex_unlock(&global_detector.lock);
}
```

### 4.1 弱引用创建与访问

```c
// weak_ref.c
typedef struct WeakRefInternal {
    WeakReference base;
    ObjectHeader* original_target;  // 原始目标

WeakReference* weak_ref_create(void* obj) {
    if (!obj) return NULL;
    
    ObjectHeader* target = HEADER(obj);
    
    WeakRefInternal* ref = (WeakRefInternal*)malloc(sizeof(WeakRefInternal));
    ref->base.target = target;
    ref->base.on_clear = NULL;
    ref->base.next = NULL;
    ref->original_target = target;
    
    // 注册到全局表
    pthread_mutex_lock(&g_weak_registry.lock);
    ref->base.next = g_weak_registry.refs;
    g_weak_registry.refs = (WeakReference*)ref;
    pthread_mutex_unlock(&g_weak_registry.lock);
    
    return (WeakReference*)ref;
}

void* weak_ref_get(WeakReference* ref) {
    if (!ref) return NULL;
    
    // 检查目标是否仍然有效
    if (ref->target && ref->target->ref_count > 0) {
        return DATA(ref->target);
    }
    
    return NULL;  // 目标已被回收
}
```

### 4.2 弱引用清理

```c
void weak_ref_clear_target(ObjectHeader* target) {
    pthread_mutex_lock(&g_weak_registry.lock);
    
    WeakReference* prev = NULL;
    WeakReference* curr = g_weak_registry.refs;
    
    while (curr) {
        if (curr->target == target) {
            // 标记为无效
            curr->target = NULL;
            
            // 调用清理回调
            if (curr->on_clear) {
                curr->on_clear(curr);
            }
        }
        prev = curr;
        curr = curr->next;
    }
    
    pthread_mutex_unlock(&g_weak_registry.lock);
}
```

## 五、自动释放池 (优化高频场景)

```c
// autorelease_pool.h
typedef struct AutoReleasePool {
    void** objects;          // 对象指针数组
    uint32_t capacity;       // 容量
    uint32_t count;          // 当前数量
    struct AutoReleasePool* parent;  // 父池
} AutoReleasePool;

// 线程局部存储
static __thread AutoReleasePool* g_current_pool = NULL;

AutoReleasePool* pool_create(void) {
    AutoReleasePool* pool = (AutoReleasePool*)malloc(sizeof(AutoReleasePool));
    pool->capacity = 16;
    pool->count = 0;
    pool->objects = (void**)malloc(pool->capacity * sizeof(void*));
    pool->parent = g_current_pool;
    g_current_pool = pool;
    return pool;
}

void pool_destroy(AutoReleasePool* pool) {
    // 释放池中所有对象
    for (uint32_t i = 0; i < pool->count; i++) {
        release(pool->objects[i]);
    }
    
    free(pool->objects);
    g_current_pool = pool->parent;
    free(pool);
}

void pool_add_object(void* obj) {
    if (!g_current_pool) return;
    
    AutoReleasePool* pool = g_current_pool;
    
    // 扩容
    if (pool->count >= pool->capacity) {
        pool->capacity *= 2;
        pool->objects = (void**)realloc(pool->objects, 
                                        pool->capacity * sizeof(void*));
    }
    
    // 添加到池中
    pool->objects[pool->count++] = obj;
    retain(obj);  // 池持有引用
}

// 使用示例
void process_large_data() {
    AutoReleasePool* pool = pool_create();
    
    for (int i = 0; i < 1000000; i++) {
        String* s = new String("temporary");
        pool_add_object(s);
        // s会在pool_destroy时统一释放
    }
    
    pool_destroy(pool);  // 一次性释放所有临时对象
}
```

```c
void gc_configure(GCConfig* config) {
    // 应用配置到全局
    memcpy(&g_gc_config, config, sizeof(GCConfig));

    if (config->cycle_detection.enabled) {
        global_detector.scan_interval = config->cycle_detection.scan_interval_ms;
        global_detector.max_scan_objects = config->cycle_detection.max_objects_per_scan;
    }
}
```

```rust
// src/lexer/token.rs
use std::fmt;

#[derive(Debug, Clone, PartialEq)]
pub enum TokenKind {
    // 关键字
    Class, Interface, Extends, Implements, Abstract, Virtual,
    Override, Final, Static, Public, Private, Reflectable,
    New, Delete, Null, True, False,
    If, Else, For, While, Return, Break, Continue,
    Try, Catch, Throw, Import, Package, Extern,
    Sizeof, TypeId, This, Super, InstanceOf,
    
    // 标识符和字面量
    Identifier(String),
    IntegerLiteral(i64),
    FloatLiteral(f64),
    StringLiteral(String),
    CharLiteral(char),
    
    // 运算符
    Plus, Minus, Star, Slash, Percent,          // + - * / %
    Amp, Pipe, Caret, Tilde,                    // & | ^ ~
    Lt, Gt, Le, Ge, Eq, Ne,                     // < > <= >= == !=
    And, Or,                                    // && ||
    Assign, PlusAssign, MinusAssign,            // = += -=
    StarAssign, SlashAssign, PercentAssign,     // *= /= %=
    AndAssign, OrAssign, XorAssign,             // &= |= ^=
    Shl, Shr,                                   // << >>
    ShlAssign, ShrAssign,                       // <<= >>=
    Inc, Dec,                                   // ++ --
    Arrow,                                      // ->
    
    // 分隔符
    LeftParen, RightParen,      // ( )
    LeftBrace, RightBrace,      // { }
    LeftBracket, RightBracket,  // [ ]
    Comma, Dot, Semicolon, Colon, Question,
    
    // 特殊
    EndOfFile,
    Error(String),
}

#[derive(Debug, Clone)]
pub struct Token {
    pub kind: TokenKind,
    pub span: Span,
}

#[derive(Debug, Clone, Copy, PartialEq)]
pub struct Span {
    pub start: usize,   // 字节偏移
    pub end: usize,
    pub line: usize,
    pub column: usize,
}

impl Token {
    pub fn new(kind: TokenKind, span: Span) -> Self {
        Self { kind, span }
    }
    
    pub fn is_keyword(&self) -> bool {
        matches!(self.kind,
            TokenKind::Class | TokenKind::Interface | TokenKind::Extends |
            TokenKind::Implements | TokenKind::Virtual | TokenKind::Override |
            TokenKind::If | TokenKind::Else | TokenKind::For | TokenKind::While |
            TokenKind::Return | TokenKind::New | TokenKind::Delete
        )
    }
    
    pub fn keyword_to_string(&self) -> Option<&'static str> {
        match &self.kind {
            TokenKind::Class => Some("class"),
            TokenKind::Interface => Some("interface"),
            TokenKind::Extends => Some("extends"),
            TokenKind::Implements => Some("implements"),
            TokenKind::Virtual => Some("virtual"),
            TokenKind::Override => Some("override"),
            TokenKind::If => Some("if"),
            TokenKind::Else => Some("else"),
            TokenKind::For => Some("for"),
            TokenKind::While => Some("while"),
            TokenKind::Return => Some("return"),
            TokenKind::New => Some("new"),
            TokenKind::Delete => Some("delete"),
            _ => None,
        }
    }
}
```

### 2.3 词法分析器实现

```rust
// src/lexer/lexer.rs
use super::token::{Token, TokenKind, Span};
use std::iter::Peekable;
use std::str::Chars;

pub struct Lexer<'a> {
    source: &'a str,
    chars: Peekable<Chars<'a>>,
    pos: usize,      // 当前字节偏移
    line: usize,
    col: usize,
}

impl<'a> Lexer<'a> {
    pub fn new(source: &'a str) -> Self {
        Self {
            source,
            chars: source.chars().peekable(),
            pos: 0,
            line: 1,
            col: 1,
        }
    }
    
    pub fn next_token(&mut self) -> Token {
        self.skip_whitespace();
        
        let start_pos = self.pos;
        let start_line = self.line;
        let start_col = self.col;
        
        match self.peek_char() {
            None => return self.make_token(TokenKind::EndOfFile, start_pos, start_pos),
            
            // 单字符符号
            Some('(') => { self.advance(); self.make_token(TokenKind::LeftParen, start_pos, self.pos) }
            Some(')') => { self.advance(); self.make_token(TokenKind::RightParen, start_pos, self.pos) }
            Some('{') => { self.advance(); self.make_token(TokenKind::LeftBrace, start_pos, self.pos) }
            Some('}') => { self.advance(); self.make_token(TokenKind::RightBrace, start_pos, self.pos) }
            Some('[') => { self.advance(); self.make_token(TokenKind::LeftBracket, start_pos, self.pos) }
            Some(']') => { self.advance(); self.make_token(TokenKind::RightBracket, start_pos, self.pos) }
            Some(',') => { self.advance(); self.make_token(TokenKind::Comma, start_pos, self.pos) }
            Some('.') => { self.advance(); self.make_token(TokenKind::Dot, start_pos, self.pos) }
            Some(';') => { self.advance(); self.make_token(TokenKind::Semicolon, start_pos, self.pos) }
            Some(':') => { self.advance(); self.make_token(TokenKind::Colon, start_pos, self.pos) }
            Some('?') => { self.advance(); self.make_token(TokenKind::Question, start_pos, self.pos) }
            Some('~') => { self.advance(); self.make_token(TokenKind::Tilde, start_pos, self.pos) }
            
            // 运算符
            Some('+') => {
                self.advance();
                match self.peek_char() {
                    Some('+') => { self.advance(); self.make_token(TokenKind::Inc, start_pos, self.pos) }
                    Some('=') => { self.advance(); self.make_token(TokenKind::PlusAssign, start_pos, self.pos) }
                    _ => self.make_token(TokenKind::Plus, start_pos, self.pos)
                }
            }
            Some('-') => {
                self.advance();
                match self.peek_char() {
                    Some('-') => { self.advance(); self.make_token(TokenKind::Dec, start_pos, self.pos) }
                    Some('=') => { self.advance(); self.make_token(TokenKind::MinusAssign, start_pos, self.pos) }
                    Some('>') => { self.advance(); self.make_token(TokenKind::Arrow, start_pos, self.pos) }
                    _ => self.make_token(TokenKind::Minus, start_pos, self.pos)
                }
            }
            Some('*') => {
                self.advance();
                if self.peek_char() == Some('=') {
                    self.advance();
                    self.make_token(TokenKind::StarAssign, start_pos, self.pos)
                } else {
                    self.make_token(TokenKind::Star, start_pos, self.pos)
                }
            }
            Some('/') => {
                self.advance();
                match self.peek_char() {
                    Some('/') => {
                        // 单行注释
                        self.skip_line_comment();
                        return self.next_token();
                    }
                    Some('*') => {
                        // 多行注释
                        self.skip_block_comment();
                        return self.next_token();
                    }
                    Some('=') => {
                        self.advance();
                        self.make_token(TokenKind::SlashAssign, start_pos, self.pos)
                    }
                    _ => self.make_token(TokenKind::Slash, start_pos, self.pos)
                }
            }
            Some('%') => {
                self.advance();
                if self.peek_char() == Some('=') {
                    self.advance();
                    self.make_token(TokenKind::PercentAssign, start_pos, self.pos)
                } else {
                    self.make_token(TokenKind::Percent, start_pos, self.pos)
                }
            }
            Some('&') => {
                self.advance();
                match self.peek_char() {
                    Some('&') => { self.advance(); self.make_token(TokenKind::And, start_pos, self.pos) }
                    Some('=') => { self.advance(); self.make_token(TokenKind::AndAssign, start_pos, self.pos) }
                    _ => self.make_token(TokenKind::Amp, start_pos, self.pos)
                }
            }
            Some('|') => {
                self.advance();
                match self.peek_char() {
                    Some('|') => { self.advance(); self.make_token(TokenKind::Or, start_pos, self.pos) }
                    Some('=') => { self.advance(); self.make_token(TokenKind::OrAssign, start_pos, self.pos) }
                    _ => self.make_token(TokenKind::Pipe, start_pos, self.pos)
                }
            }
            Some('^') => {
                self.advance();
                if self.peek_char() == Some('=') {
                    self.advance();
                    self.make_token(TokenKind::XorAssign, start_pos, self.pos)
                } else {
                    self.make_token(TokenKind::Caret, start_pos, self.pos)
                }
            }
            Some('<') => {
                self.advance();
                match self.peek_char() {
                    Some('<') => {
                        self.advance();
                        if self.peek_char() == Some('=') {
                            self.advance();
                            self.make_token(TokenKind::ShlAssign, start_pos, self.pos)
                        } else {
                            self.make_token(TokenKind::Shl, start_pos, self.pos)
                        }
                    }
                    Some('=') => { self.advance(); self.make_token(TokenKind::Le, start_pos, self.pos) }
                    _ => self.make_token(TokenKind::Lt, start_pos, self.pos)
                }
            }
            Some('>') => {
                self.advance();
                match self.peek_char() {
                    Some('>') => {
                        self.advance();
                        if self.peek_char() == Some('=') {
                            self.advance();
                            self.make_token(TokenKind::ShrAssign, start_pos, self.pos)
                        } else {
                            self.make_token(TokenKind::Shr, start_pos, self.pos)
                        }
                    }
                    Some('=') => { self.advance(); self.make_token(TokenKind::Ge, start_pos, self.pos) }
                    _ => self.make_token(TokenKind::Gt, start_pos, self.pos)
                }
            }
            Some('=') => {
                self.advance();
                if self.peek_char() == Some('=') {
                    self.advance();
                    self.make_token(TokenKind::Eq, start_pos, self.pos)
                } else {
                    self.make_token(TokenKind::Assign, start_pos, self.pos)
                }
            }
            Some('!') => {
                self.advance();
                if self.peek_char() == Some('=') {
                    self.advance();
                    self.make_token(TokenKind::Ne, start_pos, self.pos)
                } else {
                    self.make_token(TokenKind::Error("Unexpected '!'".to_string()), start_pos, self.pos)
                }
            }
            
            // 字符串
            Some('"') => return self.read_string(),
            
            // 字符
            Some('\'') => return self.read_char(),
            
            // 数字
            Some(c) if c.is_ascii_digit() => return self.read_number(start_pos, start_line, start_col),
            
            // 标识符或关键字
            Some(c) if c.is_alphabetic() || c == '_' => return self.read_identifier(start_pos, start_line, start_col),
            
            _ => {
                let c = self.advance();
                self.make_token(TokenKind::Error(format!("Unexpected character: '{}'", c)), start_pos, self.pos)
            }
        }
    }
    
    // 辅助方法
    fn peek_char(&mut self) -> Option<char> {
        self.chars.peek().copied()
    }
    
    fn advance(&mut self) -> char {
        let c = self.chars.next().unwrap_or('\0');
        self.pos += c.len_utf8();
        if c == '\n' {
            self.line += 1;
            self.col = 1;
        } else {
            self.col += 1;
        }
        c
    }
    
    fn skip_whitespace(&mut self) {
        while let Some(c) = self.peek_char() {
            if c.is_whitespace() && c != '\n' {
                self.advance();
            } else {
                break;
            }
        }
    }
    
    fn skip_line_comment(&mut self) {
        while let Some(c) = self.peek_char() {
            if c == '\n' {
                self.advance();
                break;
            }
            self.advance();
        }
    }
    
    fn skip_block_comment(&mut self) {
        while let Some(c) = self.peek_char() {
            if c == '*' && self.chars.clone().nth(1) == Some('/') {
                self.advance(); // skip '*'
                self.advance(); // skip '/'
                break;
            }
            self.advance();
        }
    }
    
    fn read_string(&mut self) -> Token {
        let start_pos = self.pos;
        let start_line = self.line;
        let start_col = self.col;
        self.advance(); // skip opening "
        
        let mut value = String::new();
        
        while let Some(c) = self.peek_char() {
            match c {
                '"' => {
                    self.advance();
                    let end_pos = self.pos;
                    return Token {
                        kind: TokenKind::StringLiteral(value),
                        span: Span { start: start_pos, end: end_pos, line: start_line, column: start_col },
                    };
                }
                '\\' => {
                    self.advance();
                    match self.peek_char() {
                        Some('n') => { value.push('\n'); self.advance(); }
                        Some('t') => { value.push('\t'); self.advance(); }
                        Some('r') => { value.push('\r'); self.advance(); }
                        Some('\\') => { value.push('\\'); self.advance(); }
                        Some('"') => { value.push('"'); self.advance(); }
                        Some(c) => { value.push(c); self.advance(); }
                        None => break,
                    }
                }
                _ => {
                    value.push(c);
                    self.advance();
                }
            }
        }
        
        self.make_token(TokenKind::Error("Unterminated string".to_string()), start_pos, self.pos)
    }
    
    fn read_char(&mut self) -> Token {
        let start_pos = self.pos;
        let start_line = self.line;
        let start_col = self.col;
        self.advance(); // skip opening '
        
        let value = match self.peek_char() {
            Some('\\') => {
                self.advance();
                match self.peek_char() {
                    Some('n') => { self.advance(); '\n' }
                    Some('t') => { self.advance(); '\t' }
                    Some('r') => { self.advance(); '\r' }
                    Some('\\') => { self.advance(); '\\' }
                    Some('\'') => { self.advance(); '\'' }
                    Some(c) => { self.advance(); c }
                    None => '\0',
                }
            }
            Some(c) => {
                self.advance();
                c
            }
            None => '\0',
        };
        
        if self.peek_char() == Some('\'') {
            self.advance();
            let end_pos = self.pos;
            self.make_token(TokenKind::CharLiteral(value), start_pos, end_pos)
        } else {
            self.make_token(TokenKind::Error("Unterminated char literal".to_string()), start_pos, self.pos)
        }
    }
    
    fn read_number(&mut self, start_pos: usize, start_line: usize, start_col: usize) -> Token {
        let mut is_float = false;
        
        while let Some(c) = self.peek_char() {
            if c.is_ascii_digit() {
                self.advance();
            } else if c == '.' && !is_float {
                is_float = true;
                self.advance();
            } else {
                break;
            }
        }
        
        let num_str = &self.source[start_pos..self.pos];
        let end_pos = self.pos;
        
        if is_float {
            match num_str.parse::<f64>() {
                Ok(val) => Token {
                    kind: TokenKind::FloatLiteral(val),
                    span: Span { start: start_pos, end: end_pos, line: start_line, column: start_col },
                },
                Err(_) => self.make_token(TokenKind::Error("Invalid float literal".to_string()), start_pos, end_pos),
            }
        } else {
            match num_str.parse::<i64>() {
                Ok(val) => Token {
                    kind: TokenKind::IntegerLiteral(val),
                    span: Span { start: start_pos, end: end_pos, line: start_line, column: start_col },
                },
                Err(_) => self.make_token(TokenKind::Error("Integer too large".to_string()), start_pos, end_pos),
            }
        }
    }
    
    fn read_identifier(&mut self, start_pos: usize, start_line: usize, start_col: usize) -> Token {
        while let Some(c) = self.peek_char() {
            if c.is_alphanumeric() || c == '_' {
                self.advance();
            } else {
                break;
            }
        }
        
        let ident = &self.source[start_pos..self.pos];
        let end_pos = self.pos;
        
        let kind = match ident {
            "class" => TokenKind::Class,
            "interface" => TokenKind::Interface,
            "extends" => TokenKind::Extends,
            "implements" => TokenKind::Implements,
            "abstract" => TokenKind::Abstract,
            "virtual" => TokenKind::Virtual,
            "override" => TokenKind::Override,
            "final" => TokenKind::Final,
            "static" => TokenKind::Static,
            "public" => TokenKind::Public,
            "private" => TokenKind::Private,
            "reflectable" => TokenKind::Reflectable,
            "new" => TokenKind::New,
            "delete" => TokenKind::Delete,
            "null" => TokenKind::Null,
            "true" => TokenKind::True,
            "false" => TokenKind::False,
            "if" => TokenKind::If,
            "else" => TokenKind::Else,
            "for" => TokenKind::For,
            "while" => TokenKind::While,
            "return" => TokenKind::Return,
            "break" => TokenKind::Break,
            "continue" => TokenKind::Continue,
            "try" => TokenKind::Try,
            "catch" => TokenKind::Catch,
            "throw" => TokenKind::Throw,
            "import" => TokenKind::Import,
            "package" => TokenKind::Package,
            "extern" => TokenKind::Extern,
            "sizeof" => TokenKind::Sizeof,
            "typeid" => TokenKind::TypeId,
            "this" => TokenKind::This,
            "super" => TokenKind::Super,
            "instanceof" => TokenKind::InstanceOf,
            _ => TokenKind::Identifier(ident.to_string()),
        };
        
        Token {
            kind,
            span: Span { start: start_pos, end: end_pos, line: start_line, column: start_col },
        }
    }
    
    fn make_token(&self, kind: TokenKind, start: usize, end: usize) -> Token {
        Token {
            kind,
            span: Span { start, end, line: self.line, column: self.col },
        }
    }
}

impl<'a> Iterator for Lexer<'a> {
    type Item = Token;
    
    fn next(&mut self) -> Option<Self::Item> {
        let token = self.next_token();
        if matches!(token.kind, TokenKind::EndOfFile) {
            None
        } else {
            Some(token)
        }
    }
}
```

```rust
// src/main.rs
mod lexer;
mod ast;
mod diagnostics;

use lexer::lexer::Lexer;
use std::env;
use std::fs;

fn main() {
    let args: Vec<String> = env::args().collect();
    
    if args.len() < 2 {
        eprintln!("Usage: lemonc <file.lm>");
        std::process::exit(1);
    }
    
    let source = fs::read_to_string(&args[1]).expect("Failed to read file");
    let mut lexer = Lexer::new(&source);
    
    println!("Tokenizing {}...\n", args[1]);
    println!("{:<20} {:<10} {:<10} {:<10}", "Token", "Line", "Col", "Value");
    println!("{}", "-".repeat(60));
    
    while let Some(token) = lexer.next() {
        let value = match &token.kind {
            lexer::token::TokenKind::Identifier(s) => s.as_str(),
            lexer::token::TokenKind::StringLiteral(s) => s.as_str(),
            lexer::token::TokenKind::IntegerLiteral(i) => {
                let mut buf = String::new();
                write!(&mut buf, "{}", i).unwrap();
                &buf
            }
            _ => "",
        };
        
        println!("{:20?} {:<10} {:<10} {}",
            token.kind,
            token.span.line,
            token.span.column,
            value
        );
    }
    
    println!("\n✅ Lexing complete!");
}
```

```java
// std/core/String.lm
package std.core;

@reflectable
public class String {
    private byte[] _bytes;   // UTF-8 bytes
    private int _length;      // 字符数 (非字节数)
    
    // 构造函数
    public String() {
        this._bytes = new byte[0];
        this._length = 0;
    }
    
    public String(byte[] bytes) {
        this._bytes = bytes;
        this._length = utf8_length(bytes);
    }
    
    public String(const char* cstr) {
        this._bytes = string_to_bytes(cstr);
        this._length = utf8_length(this._bytes);
    }
    
    // 静态工厂方法
    public static String fromUtf8(byte[] bytes) {
        return new String(bytes);
    }
    
    public static String fromChar(char c) {
        return new String(new byte[] { (byte)c });
    }
    
    // 实例方法
    public int length() {
        return this._length;
    }
    
    public char charAt(int index) {
        // UTF-8解码
        return decode_utf8(this._bytes, index);
    }
    
    public String substring(int start, int end) {
        byte[] slice = this._bytes.slice(start, end);
        return new String(slice);
    }
    
    public String concat(String other) {
        byte[] combined = new byte[this._bytes.length + other._bytes.length];
        System.arraycopy(this._bytes, 0, combined, 0, this._bytes.length);
        System.arraycopy(other._bytes, 0, combined, this._bytes.length, other._bytes.length);
        return new String(combined);
    }
    
    public String toUpperCase() {
        // 实现略
        return this;
    }
    
    public String toLowerCase() {
        // 实现略
        return this;
    }
    
    public String trim() {
        // 去除首尾空白
        int start = 0;
        int end = this._bytes.length;
        while (start < end && is_whitespace(this._bytes[start])) start++;
        while (end > start && is_whitespace(this._bytes[end - 1])) end--;
        return this.substring(start, end);
    }
    
    public bool contains(String substr) {
        return this.indexOf(substr) != -1;
    }
    
    public int indexOf(String substr) {
        // KMP 或简单查找
        return find_substring(this._bytes, substr._bytes);
    }
    
    public String[] split(String delimiter) {
        // 实现分割
        return new String[0];
    }
    
    public bool equals(Object other) {
        if (!(other instanceof String)) return false;
        String s = (String)other;
        return this._bytes.equals(s._bytes);
    }
    
    public int hashCode() {
        return hash_bytes(this._bytes);
    }
    
    public String toString() {
        return this;
    }
    
    // 运算符重载 (语法糖)
    public String operator+(String other) {
        return this.concat(other);
    }
    
    public bool operator==(String other) {
        return this.equals(other);
    }
    
    // 私有辅助方法
    private static int utf8_length(byte[] bytes) {
        int len = 0;
        for (int i = 0; i < bytes.length; i++) {
            if ((bytes[i] & 0xC0) != 0x80) len++;  // 非后续字节
        }
        return len;
    }
    
    private static int find_substring(byte[] haystack, byte[] needle) {
        if (needle.length == 0) return 0;
        for (int i = 0; i <= haystack.length - needle.length; i++) {
            bool found = true;
            for (int j = 0; j < needle.length; j++) {
                if (haystack[i + j] != needle[j]) {
                    found = false;
                    break;
                }
            }
            if (found) return i;
        }
        return -1;
    }
    
    private static int hash_bytes(byte[] bytes) {
        int hash = 0;
        for (int i = 0; i < bytes.length; i++) {
            hash = 31 * hash + (bytes[i] & 0xFF);
        }
        return hash;
    }
    
    @extern(header: "<ctype.h>")
    private static bool is_whitespace(byte c);
    
    @extern(header: "<string.h>")
    private static void* memcpy(void* dest, void* src, int n);
}
```

### 3.2 集合示例: ArrayList.lm

```java
// std/collections/ArrayList.lm
package std.collections;

import std.core.String;
import std.core.Array;

@reflectable
public class ArrayList<T> {
    private static final int DEFAULT_CAPACITY = 16;
    
    private T[] _elements;
    private int _size;
    
    public ArrayList() {
        this._elements = new T[DEFAULT_CAPACITY];
        this._size = 0;
    }
    
    public ArrayList(int initialCapacity) {
        this._elements = new T[initialCapacity];
        this._size = 0;
    }
    
    public int size() {
        return this._size;
    }
    
    public bool isEmpty() {
        return this._size == 0;
    }
    
    public void add(T element) {
        if (this._size == this._elements.length) {
            this._resize();
        }
        this._elements[this._size++] = element;
    }
    
    public void addAt(int index, T element) {
        if (index < 0 || index > this._size) {
            throw new IndexOutOfBoundsException();
        }
        
        if (this._size == this._elements.length) {
            this._resize();
        }
        
        // 移动元素
        for (int i = this._size; i > index; i--) {
            this._elements[i] = this._elements[i - 1];
        }
        this._elements[index] = element;
        this._size++;
    }
    
    public T get(int index) {
        if (index < 0 || index >= this._size) {
            throw new IndexOutOfBoundsException();
        }
        return this._elements[index];
    }
    
    public T set(int index, T element) {
        if (index < 0 || index >= this._size) {
            throw new IndexOutOfBoundsException();
        }
        T old = this._elements[index];
        this._elements[index] = element;
        return old;
    }
    
    public T remove(int index) {
        if (index < 0 || index >= this._size) {
            throw new IndexOutOfBoundsException();
        }
        T old = this._elements[index];
        
        for (int i = index; i < this._size - 1; i++) {
            this._elements[i] = this._elements[i + 1];
        }
        this._size--;
        this._elements[this._size] = null;  // 帮助GC
        
        return old;
    }
    
    public bool remove(T element) {
        for (int i = 0; i < this._size; i++) {
            if (this._elements[i].equals(element)) {
                this.remove(i);
                return true;
            }
        }
        return false;
    }
    
    public void clear() {
        for (int i = 0; i < this._size; i++) {
            this._elements[i] = null;
        }
        this._size = 0;
    }
    
    public T[] toArray() {
        T[] copy = new T[this._size];
        System.arraycopy(this._elements, 0, copy, 0, this._size);
        return copy;
    }
    
    public Iterator<T> iterator() {
        return new ArrayListIterator<T>(this);
    }
    
    private void _resize() {
        int newCapacity = this._elements.length * 2;
        T[] newElements = new T[newCapacity];
        System.arraycopy(this._elements, 0, newElements, 0, this._size);
        this._elements = newElements;
    }
}

// 迭代器实现
public class ArrayListIterator<T> implements Iterator<T> {
    private ArrayList<T> _list;
    private int _position;
    
    public ArrayListIterator(ArrayList<T> list) {
        this._list = list;
        this._position = 0;
    }
    
    @override
    public bool hasNext() {
        return this._position < this._list.size();
    }
    
    @override
    public T next() {
        if (!this.hasNext()) {
            throw new NoSuchElementException();
        }
        return this._list.get(this._position++);
    }
    
    @override
    public void remove() {
        this._list.remove(this._position - 1);
    }
}
```

```java
        }
```

## 二、IR生成器（从AST）

### 2.1 IR生成器主类

```rust
// ir/gen.rs
use super::instruction::*;
use super::type_system::*;
use crate::ast::*;
use std::collections::HashMap;

pub struct IRGenerator {
    module: IRModule,
    current_function: Option<String>,
    bb_counter: u32,
    value_counter: u32,
    phi_stack: Vec<HashMap<IRValue, IRValue>>,
}

impl IRGenerator {
    pub fn new() -> Self {
        Self {
            module: IRModule::new(),
            current_function: None,
            bb_counter: 0,
            value_counter: 0,
            phi_stack: Vec::new(),
        }
    }
    
    pub fn generate(&mut self, ast: &AST) -> IRModule {
        for decl in &ast.declarations {
            match decl {
                ASTNode::Class(class) => self.generate_class(class),
                ASTNode::Function(func) => self.generate_function(func),
                ASTNode::Interface(iface) => self.generate_interface(iface),
                _ => {},
            }
        }
        self.module.clone()
    }
    
    // 生成函数
    fn generate_function(&mut self, func: &FunctionDecl) {
        let ir_func = IRFunction::new(&func.name);
        self.current_function = Some(func.name.clone());
        
        // 进入函数
        self.enter_function();
        
        // 创建入口基本块
        let entry_bb = self.new_basic_block("entry");
        self.set_current_bb(entry_bb);
        
        // 处理参数
        for (i, param) in func.params.iter().enumerate() {
            let ir_param = self.new_value(&param.typ, &format!("arg{}", i));
            ir_func.add_param(ir_param.clone());
            self.set_variable(&param.name, ir_param);
        }
        
        // 生成函数体
        self.generate_statement(&func.body);
        
        // 退出函数
        self.exit_function();
    }
    
    // 生成表达式
    fn generate_expression(&mut self, expr: &Expr) -> IRValue {
        match expr {
            Expr::IntegerLiteral(val) => {
                self.new_const_int(*val)
            }
            Expr::FloatLiteral(val) => {
                self.new_const_float(*val)
            }
            Expr::StringLiteral(s) => {
                self.generate_string_literal(s)
            }
            Expr::Variable(name) => {
                self.get_variable(name).unwrap()
            }
            Expr::BinaryOp(op, left, right) => {
                let l = self.generate_expression(left);
                let r = self.generate_expression(right);
                self.generate_binary_op(op, l, r)
            }
            Expr::Assignment(target, value) => {
                let val = self.generate_expression(value);
                self.emit(IRInstruction::Store(val, target.clone()));
                val
            }
            Expr::MethodCall(obj, method, args) => {
                self.generate_method_call(obj, method, args)
            }
            Expr::New(class_name, args) => {
                self.generate_new_object(class_name, args)
            }
            _ => unimplemented!()
        }
    }
    
    // 生成方法调用（支持虚表和接口）
    fn generate_method_call(&mut self, obj: &Expr, method: &str, args: &[Expr]) -> IRValue {
        let obj_val = self.generate_expression(obj);
        let obj_type = self.get_type(obj_val.clone());
        
        // 查找方法表
        if let Some(vtable_index) = self.find_vtable_index(&obj_type, method) {
            // 虚方法调用
            let mut call_args = vec![obj_val];
            for arg in args {
                call_args.push(self.generate_expression(arg));
            }
            let result = self.new_temporary(&IRType::Unknown);
            self.emit(IRInstruction::VCall(obj_val, vtable_index, call_args));
            result
        } else if let Some(itable_index) = self.find_itable_index(&obj_type, method) {
            // 接口方法调用
            let mut call_args = vec![obj_val];
            for arg in args {
                call_args.push(self.generate_expression(arg));
            }
            let result = self.new_temporary(&IRType::Unknown);
            self.emit(IRInstruction::ICall(obj_val, itable_index, call_args));
            result
        } else {
            // 静态方法调用
            self.generate_static_call(method, args)
        }
    }
    
    // 生成对象分配（带GC）
    fn generate_new_object(&mut self, class_name: &str, args: &[Expr]) -> IRValue {
        // 获取类型信息
        let class_info = self.module.get_class(class_name).unwrap();
        
        // 计算对象大小
        let size = class_info.instance_size;
        
        // 分配对象
        let obj_ptr = self.new_temporary(&IRType::Object);
        self.emit(IRInstruction::GcAlloc(IRType::Object));
        
        // 初始化对象头
        self.emit(IRInstruction::Store(
            self.new_const_int(1),  // ref_count = 1
            self.gep(obj_ptr.clone(), vec![self.new_const_int(0)])
        ));
        
        // 调用构造函数
        self.generate_call(&class_info.constructor, args, Some(obj_ptr.clone()));
        
        obj_ptr
    }
}
```

### 3.1 线性扫描寄存器分配

```rust
// ir/regalloc.rs
use std::collections::{HashMap, BinaryHeap};
use std::cmp::Ordering;

#[derive(Debug, Clone)]
struct LiveInterval {
    vreg: u32,
    start: u32,
    end: u32,
    hint: Option<u32>,  // 寄存器提示
}

#[derive(Debug)]
struct PhysicalRegister {
    id: u32,
    name: String,
    is_callee_saved: bool,
    is_available: bool,
}

pub struct LinearScanAllocator {
    registers: Vec<PhysicalRegister>,
    next_vreg: u32,
    active: BinaryHeap<LiveInterval>,
    assignments: HashMap<u32, u32>,  // vreg -> preg
    spill_slots: HashMap<u32, u32>,  // vreg -> stack slot
}

impl LinearScanAllocator {
    pub fn new() -> Self {
        let registers = vec![
            // 通用寄存器
            PhysicalRegister { id: 0, name: "rax".to_string(), is_callee_saved: false, is_available: true },
            PhysicalRegister { id: 1, name: "rcx".to_string(), is_callee_saved: false, is_available: true },
            PhysicalRegister { id: 2, name: "rdx".to_string(), is_callee_saved: false, is_available: true },
            PhysicalRegister { id: 3, name: "rbx".to_string(), is_callee_saved: true, is_available: true },
            PhysicalRegister { id: 4, name: "rsi".to_string(), is_callee_saved: false, is_available: true },
            PhysicalRegister { id: 5, name: "rdi".to_string(), is_callee_saved: false, is_available: true },
            PhysicalRegister { id: 6, name: "r8".to_string(), is_callee_saved: false, is_available: true },
            PhysicalRegister { id: 7, name: "r9".to_string(), is_callee_saved: false, is_available: true },
            PhysicalRegister { id: 8, name: "r10".to_string(), is_callee_saved: false, is_available: true },
            PhysicalRegister { id: 9, name: "r11".to_string(), is_callee_saved: false, is_available: true },
            PhysicalRegister { id: 10, name: "r12".to_string(), is_callee_saved: true, is_available: true },
            PhysicalRegister { id: 11, name: "r13".to_string(), is_callee_saved: true, is_available: true },
            PhysicalRegister { id: 12, name: "r14".to_string(), is_callee_saved: true, is_available: true },
            PhysicalRegister { id: 13, name: "r15".to_string(), is_callee_saved: true, is_available: true },
        ];
        
        Self {
            registers,
            next_vreg: 0,
            active: BinaryHeap::new(),
            assignments: HashMap::new(),
            spill_slots: HashMap::new(),
        }
    }
    
    pub fn allocate(&mut self, intervals: Vec<LiveInterval>) -> HashMap<u32, u32> {
        let mut sorted = intervals;
        sorted.sort_by(|a, b| a.start.cmp(&b.start));
        
        for interval in sorted {
            self.expire_old_intervals(interval.start);
            
            if self.active.len() >= self.registers.len() {
                self.spill_at_interval(interval);
            } else {
                self.assign_register(interval);
            }
        }
        
        self.assignments.clone()
    }
    
    fn expire_old_intervals(&mut self, current_pos: u32) {
        while let Some(active) = self.active.peek() {
            if active.end >= current_pos {
                break;
            }
            let expired = self.active.pop().unwrap();
            let preg = self.assignments[&expired.vreg];
            self.registers[preg as usize].is_available = true;
        }
    }
    
    fn spill_at_interval(&mut self, interval: LiveInterval) {
        // 找最晚结束的活跃区间
        let mut to_spill = None;
        let mut max_end = 0;
        
        for active in self.active.iter() {
            if active.end > max_end {
                max_end = active.end;
                to_spill = Some(active.vreg);
            }
        }
        
        if let Some(spill_vreg) = to_spill {
            if max_end > interval.end {
                // 溢出当前区间
                self.spill_interval(interval);
            } else {
                // 溢出最远的活跃区间
                self.spill_interval(LiveInterval {
                    vreg: spill_vreg,
                    start: 0,
                    end: 0,
                    hint: None,
                });
                self.assign_register(interval);
            }
        }
    }
    
    fn assign_register(&mut self, interval: LiveInterval) {
        // 尝试分配寄存器
        for reg in &mut self.registers {
            if reg.is_available {
                reg.is_available = false;
                self.assignments.insert(interval.vreg, reg.id);
                self.active.push(interval);
                return;
            }
        }
        
        panic!("No register available");
    }
    
    fn spill_interval(&mut self, interval: LiveInterval) {
        // 分配栈槽位
        let slot = self.spill_slots.len() as u32;
        self.spill_slots.insert(interval.vreg, slot);
    }
}
```

### 4.1 汇编生成器

```rust
// ir/codegen/x86_64.rs
use super::*;
use std::io::Write;

pub struct X86_64CodeGen {
    output: Vec<u8>,
    labels: HashMap<String, u32>,
    current_label: Option<String>,
    stack_size: u32,
    frame_pointer: bool,
}

impl X86_64CodeGen {
    pub fn new() -> Self {
        Self {
            output: Vec::new(),
            labels: HashMap::new(),
            current_label: None,
            stack_size: 0,
            frame_pointer: true,
        }
    }
    
    pub fn generate(&mut self, module: &IRModule) -> Vec<u8> {
        // 生成文本段
        self.emit_section(".text");
        
        // 生成每个函数
        for func in &module.functions {
            self.generate_function(func);
        }
        
        // 生成数据段
        self.emit_section(".data");
        for global in &module.globals {
            self.generate_global(global);
        }
        
        // 生成只读数据段（反射元数据）
        self.emit_section(".rodata");
        for metadata in &module.metadata {
            self.generate_metadata(metadata);
        }
        
        self.output.clone()
    }
    
    fn generate_function(&mut self, func: &IRFunction) {
        // 函数标签
        self.emit_label(&func.name);
        
        // 函数序言
        self.emit_prologue(func);
        
        // 生成每个基本块
        for bb in &func.basic_blocks {
            self.generate_basic_block(bb);
        }
        
        // 函数尾声
        self.emit_epilogue();
    }
    
    fn generate_basic_block(&mut self, bb: &BasicBlock) {
        // 基本块标签
        if !bb.name.is_empty() {
            self.emit_label(&bb.name);
        }
        
        // 生成指令
        for inst in &bb.instructions {
            self.generate_instruction(inst);
        }
    }
    
    fn generate_instruction(&mut self, inst: &IRInstruction) {
        match inst {
            IRInstruction::Alloca(typ) => {
                let size = self.get_type_size(typ);
                self.stack_size += size;
                // 返回栈地址
                self.emit("lea rax, [rbp - {}]", self.stack_size);
            }
            
            IRInstruction::Load(src) => {
                self.emit_mov("rax", src);
            }
            
            IRInstruction::Store(val, ptr) => {
                self.emit_mov(ptr, val);
            }
            
            IRInstruction::Add(l, r) => {
                self.emit("mov rax, {}", l);
                self.emit("add rax, {}", r);
            }
            
            IRInstruction::Sub(l, r) => {
                self.emit("mov rax, {}", l);
                self.emit("sub rax, {}", r);
            }
            
            IRInstruction::Call(func, args) => {
                // 参数传递 (System V AMD64 ABI)
                // RDI, RSI, RDX, RCX, R8, R9
                for (i, arg) in args.iter().enumerate() {
                    match i {
                        0 => self.emit("mov rdi, {}", arg),
                        1 => self.emit("mov rsi, {}", arg),
                        2 => self.emit("mov rdx, {}", arg),
                        3 => self.emit("mov rcx, {}", arg),
                        4 => self.emit("mov r8, {}", arg),
                        5 => self.emit("mov r9, {}", arg),
                        _ => {
                            // 栈传参
                            self.emit("push {}", arg);
                        }
                    }
                }
                
                self.emit("call {}", func);
                
                // 清理栈参数
                if args.len() > 6 {
                    let stack_args = args.len() - 6;
                    self.emit("add rsp, {}", stack_args * 8);
                }
            }
            
            IRInstruction::GcAlloc(typ) => {
                let size = self.get_type_size(typ);
                self.emit("mov rdi, {}", size);
                self.emit("call gc_alloc");
                // rax 包含分配的对象指针
            }
            
            IRInstruction::Retain(obj) => {
                self.emit("mov rdi, {}", obj);
                self.emit("call retain");
            }
            
            IRInstruction::Release(obj) => {
                self.emit("mov rdi, {}", obj);
                self.emit("call release");
            }
            
            IRInstruction::Ret(value) => {
                if let Some(val) = value {
                    self.emit("mov rax, {}", val);
                }
                self.emit("jmp .return");
            }
            
            IRInstruction::VCall(obj, index, args) => {
                // 加载虚表
                self.emit("mov rax, [{}]", obj);      // rax = vtable_ptr
                self.emit("mov rax, [rax + {}]", index * 8);  // rax = method_ptr
                
                // 传递参数
                for (i, arg) in args.iter().enumerate() {
                    match i {
                        0 => self.emit("mov rdi, {}", arg),
                        1 => self.emit("mov rsi, {}", arg),
                        2 => self.emit("mov rdx, {}", arg),
                        _ => self.emit("push {}", arg),
                    }
                }
                
                self.emit("call rax");
                
                if args.len() > 3 {
                    self.emit("add rsp, {}", (args.len() - 3) * 8);
                }
            }
            
            _ => unimplemented!("{:?}", inst),
        }
    }
    
    // 汇编输出辅助方法
    fn emit(&mut self, fmt: &str, args: &[&dyn AsmArg]) {
        let line = format!(fmt, args);
        self.output.write_all(line.as_bytes()).unwrap();
        self.output.write_all(b"\n").unwrap();
    }
    
    fn emit_label(&mut self, name: &str) {
        let line = format!("{}:", name);
        self.output.write_all(line.as_bytes()).unwrap();
        self.output.write_all(b"\n").unwrap();
        self.labels.insert(name.to_string(), self.output.len() as u32);
    }
    
    fn emit_section(&mut self, name: &str) {
        let line = format!("section {}", name);
        self.output.write_all(line.as_bytes()).unwrap();
        self.output.write_all(b"\n").unwrap();
    }
    
    fn emit_prologue(&mut self, func: &IRFunction) {
        self.emit("push rbp", &[]);
        self.emit("mov rbp, rsp", &[]);
        
        if self.stack_size > 0 {
            self.emit("sub rsp, {}", &[&self.stack_size]);
        }
        
        // 保存被调用者保存的寄存器
        self.emit("push rbx", &[]);
        self.emit("push r12", &[]);
        self.emit("push r13", &[]);
        self.emit("push r14", &[]);
        self.emit("push r15", &[]);
    }
    
    fn emit_epilogue(&mut self) {
        self.emit_label(".return");
        
        // 恢复寄存器
        self.emit("pop r15", &[]);
        self.emit("pop r14", &[]);
        self.emit("pop r13", &[]);
        self.emit("pop r12", &[]);
        self.emit("pop rbx", &[]);
        
        self.emit("mov rsp, rbp", &[]);
        self.emit("pop rbp", &[]);
        self.emit("ret", &[]);
    }
    
    fn emit_mov(&mut self, dest: &str, src: &IRValue) {
        match src.typ {
            IRType::Integer { bits: 32, .. } => {
                self.emit("mov {}, {}", &[&dest, &self.value_name(src)]);
            }
            IRType::Integer { bits: 64, .. } => {
                self.emit("mov {}, {}", &[&dest, &self.value_name(src)]);
            }
            IRType::Pointer(_) => {
                self.emit("mov {}, {}", &[&dest, &self.value_name(src)]);
            }
            _ => {
                self.emit("mov {}, {}", &[&dest, &self.value_name(src)]);
            }
        }
    }
    
    fn value_name(&self, val: &IRValue) -> String {
        if let Some(preg) = self.reg_alloc.assignments.get(&val.id) {
            format!("r{}", preg)
        } else if let Some(slot) = self.reg_alloc.spill_slots.get(&val.id) {
            format!("[rbp - {}]", slot * 8)
        } else {
            format!("[rbp - {}]", val.id)
        }
    }
}
```

```rust
// src/main.rs (完整版)
mod lexer;
mod parser;
mod ast;
mod ir;
mod codegen;

use std::env;
use std::fs;
use std::process::Command;

fn main() {
    let args: Vec<String> = env::args().collect();
    
    if args.len() < 2 {
        eprintln!("Usage: lemonc <file.lm> [options]");
        eprintln!("Options:");
        eprintln!("  -o <file>    Output file");
        eprintln!("  -S           Output assembly");
        eprintln!("  -c           Compile only (no linking)");
        eprintln!("  -g           Debug info");
        eprintln!("  -O<level>    Optimization level (0-3)");
        std::process::exit(1);
    }
    
    let input = &args[1];
    let source = fs::read_to_string(input).expect("Failed to read file");
    
    // 1. 词法分析
    println!("[1/5] Lexical analysis...");
    let lexer = lexer::Lexer::new(&source);
    let tokens: Vec<_> = lexer.collect();
    
    // 2. 语法分析
    println!("[2/5] Parsing...");
    let mut parser = parser::Parser::new(tokens);
    let ast = parser.parse().expect("Parse failed");
    
    // 3. IR生成
    println!("[3/5] Generating IR...");
    let mut ir_gen = ir::IRGenerator::new();
    let module = ir_gen.generate(&ast);
    
    // 4. 优化 (可选)
    println!("[4/5] Optimizing...");
    let opt_level = get_optimization_level(&args);
    let optimized = ir::optimize(module, opt_level);
    
    // 5. 代码生成
    println!("[5/5] Generating code...");
    let mut codegen = codegen::X86_64CodeGen::new();
    let assembly = codegen.generate(&optimized);
    
    // 输出
    let output_file = get_output_file(&args, input);
    if args.contains(&"-S".to_string()) {
        fs::write(&output_file, assembly).expect("Failed to write assembly");
        println!("Assembly written to {}", output_file);
    } else {
        let asm_file = output_file.replace(".o", ".s");
        fs::write(&asm_file, assembly).expect("Failed to write assembly");
        
        // 调用系统汇编器和链接器
        assemble_and_link(&asm_file, &output_file);
    }
    
    println!("✅ Compilation successful!");
}

fn assemble_and_link(asm_file: &str, output_file: &str) {
    // 汇编
    let status = Command::new("nasm")
        .args(&["-f", "elf64", asm_file, "-o", &output_file.replace(".exe", ".o")])
        .status()
        .expect("Failed to run nasm");
    
    if !status.success() {
        eprintln!("Assembly failed");
        std::process::exit(1);
    }
    
    // 链接
    let obj_file = output_file.replace(".exe", ".o");
    let status = Command::new("gcc")
        .args(&[&obj_file, "-o", output_file, "-no-pie", "-l:libruntime.a"])
        .status()
        .expect("Failed to link");
    
    if !status.success() {
        eprintln!("Linking failed");
        std::process::exit(1);
    }
}
```

## 六、运行时库 (runtime.S)

```assembly
; runtime/runtime.S
section .text
global gc_alloc, retain, release, weak_ref_create

; 函数: gc_alloc(size_t size) -> void*
gc_alloc:
    push rbp
    mov rbp, rsp
    
    ; 调用malloc
    call malloc wrt ..plt
    
    ; 初始化对象头
    test rax, rax
    jz .alloc_failed
    
    ; ref_count = 1
    mov dword [rax], 1
    
    ; type_info = NULL (稍后设置)
    mov qword [rax + 4], 0
    
    ; flags = 0
    mov word [rax + 12], 0
    
    ; padding = 0
    mov word [rax + 14], 0
    
.alloc_failed:
    pop rbp
    ret

; 函数: retain(void* obj)
retain:
    test rdi, rdi
    jz .ret
    
    ; atomic increment
    lock inc dword [rdi]
    
.ret:
    ret

; 函数: release(void* obj)
release:
    test rdi, rdi
    jz .ret
    
    ; atomic decrement
    lock dec dword [rdi]
    jnz .ret
    
    ; ref_count == 0, 释放对象
    ; 先调用析构函数
    mov rax, [rdi + 8]      ; 加载type_info
    test rax, rax
    jz .skip_dtor
    
    mov rax, [rax + 24]     ; dtor offset
    test rax, rax
    jz .skip_dtor
    
    call rax
    
.skip_dtor:
    ; 释放内存
    mov rdi, rdi
    call free wrt ..plt
    
.ret:
    ret

; 全局对象 (GC根集)
section .data
global __gc_root_set
__gc_root_set:
    dq 0  ; 根集链表头
```
